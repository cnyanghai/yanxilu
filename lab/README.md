# lab：能动的灰盒样机

2026-11-11 定的办法：先用行为定三个瞬间（一眼看全、拆包、进门），每个先做一个能动的样机，在手机上按手感过门，三个都过了再选外观。这里的东西只看手感，外观是占位的。样机是独立页面，不进 `build.py`，不碰主站代码；推到 main 以后在 `/lab` 打开（主站的离线缓存不管这个目录）。服务器上的地址没有尾斜杠，页面开头有一小段脚本补 `<base>`，新样机页照抄这一段。

## 拆包（`index.html` + `pack.js`）

一包没拆的剪报从上面送到眼前，沿封口横着划开，五张牌背朝上落到桌上，一张张点开，翻开的再点一下拿到眼前看，最后向上划或点「收下」，下一包送到。右上角切「热闹 / 安静」两种开法，旁边是声音开关。

节拍和两种开法的差别都在 `pack.js` 开头：`MODES` 一张表管强弱（顿帧、闪光、震动、火星、发牌的间隔与弧线、翻牌的时长与回弹、牌底光晕），节拍说明在文件头的注释里。

上手时请留意的几件事：

1. 划开封口的那一下，跟不跟手，一格一格的声音和震动对不对。
2. 开的那一瞬间，热闹和安静哪种对；或者各取哪一部分。
3. 发牌的快慢，五张一张张翻会不会嫌慢，「全部翻开」够不够。
4. 牌底下的光晕（越亮表示这篇越长）有没有让人想先翻哪张。
5. 拆第三包、第五包的时候还想不想拆。

技术：three.js 0.186（`vendor/three/`，自带）只画物件，字用网页排；声音是 WebAudio 现场合成的，没有音频文件；苹果手机没有震动。地址加 `?dev` 显示帧率和状态，`?mode=quiet` 直接进安静。测试 `python3 tools/tests/lab_pack_test.py`（软件渲染走一遍流程并截关键帧到 `tools/out/lab/`）。
