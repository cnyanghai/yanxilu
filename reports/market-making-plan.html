练习数据

mm_ticks.csv 是模拟数据，不是任何真实合约的行情。它按国内商品期货的日盘时段（9:00—10:15、10:30—11:30、13:30—15:00）和每秒两次的快照频率生成一天的一档盘口，最小变动价位 1 元，假设每手 10 吨。这一天开盘 3450、最高 3525、最低 3414、收盘 3488，全天成交 42,421 手，96% 的时间买卖价差是一跳。

生成规则写在脚本里：市价单随机到达、逐笔吃掉对手方的挂单，一档吃光价格就跳一格；还藏了一个每隔几分钟切换方向的“知情资金”。数据里因此藏着几个现象，第 6—8 周的习题会带你把它们找出来。

seq
序号，1 到 27000，方便做自连接（用 seq + 10 找 5 秒后的快照）
trade_date
交易日，固定为 2026-10-12（模拟）
time
快照时间，精确到毫秒，每 0.5 秒一个
bid1 / bid_vol1
买一价 / 买一挂单量（手）
ask1 / ask_vol1
卖一价 / 卖一挂单量（手）
last
最新成交价：这个快照里最后一笔成交；没有成交就沿用上一个
volume
当日累计成交量（手）。真实行情接口给的就是累计值
trade_vol
这个快照内的成交量，等于 volume 与上一个快照之差。为方便初学直接给出
open_interest
持仓量（手）

五

纸上做市（第 2、3 周）

一张纸、一支笔，或者一张 Excel 表。你是唯一的做市商，订单一笔一笔来，每笔 1 手。先自己算，再看答案。

报价你同时挂买价和卖价各 1 手，被成交后立刻在新的报价上补挂。
订单B 是对方主动买，你按卖价卖出 1 手；S 是对方主动卖，你按买价买入 1 手。
规则一：固定报价买 3449、卖 3451，始终不变。
规则二：按库存平移中心价 = 3450 − 库存（多头为正）；买价 = 中心价 − 1，卖价 = 中心价 + 1。
表格每笔一行：序号、订单、你的买价、你的卖价、成交价、库存、现金。
盈亏现金 + 库存 × 最后的中间价，单位“跳”，1 跳 = 10 元。

第 2 周：平稳的订单流最后的中间价 3450

看答案

规则一：卖出 10 手、买入 10 手，最后库存 0，过程中库存最多 2 手。现金 +20，盈亏 +20 跳（200 元）。每一笔都比中间价多赚 1 跳，20 笔就是 20 跳。

规则二：盈亏 +10 跳。有库存时报价被挪向中间价，部分成交只赚到 0 跳，平稳的日子里库存控制让你少赚了一半。

第 3 周：偏买的订单流最后的中间价 3457

看答案

规则一：卖出 15 手、买入 5 手，最后库存 −10，现金 +34,520，按 3457 盯市，盈亏 −50 跳。拆开看：每笔都多赚 1 跳，价差收入 +20 跳；但 10 手空头遇上 7 跳上涨，库存亏 70 跳。

规则二：库存同样是 −10，但随着空头增加，卖价一路抬到 3460，盈亏 −10 跳，比规则一少亏 40 跳。

两周放在一起看：平稳时库存控制少赚 10 跳，单边时少亏 40 跳。它像一份保险，平时交保费，出事时赔付。专题页“单边行情”那一天，就是没有买这份保险的结果。

第 5 周 · 先认识这张表GROUP BY、子查询

写四条查询：① 一共多少行、第一个和最后一个快照的时间；② 买卖价差（ask1 − bid1）各是几跳、各占多少比例；③ 每个小时成交了多少手；④ 当天的开盘、最高、最低、收盘价和总成交量（用 last 和 volume）。

参考答案
-- ① 行数与时间范围
SELECT COUNT(*) AS n, MIN(time) AS first_t, MAX(time) AS last_t FROM ticks;

-- ② 价差分布
SELECT ask1 - bid1 AS spread, COUNT(*) AS n,
       ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM ticks), 1) AS pct
FROM ticks GROUP BY spread ORDER BY spread;

-- ③ 每小时成交量
SELECT SUBSTR(time, 1, 2) AS hour, SUM(trade_vol) AS lots, COUNT(*) AS snaps
FROM ticks GROUP BY hour ORDER BY hour;

-- ④ 开高低收
SELECT (SELECT last FROM ticks ORDER BY seq LIMIT 1) AS open,
       MAX(last) AS high, MIN(last) AS low,
       (SELECT last FROM ticks ORDER BY seq DESC LIMIT 1) AS close,
       MAX(volume) AS total_lots
FROM ticks;

第 6 周 · 盘口失衡能不能预测下一跳自连接、CASE WHEN

盘口失衡 = (买一量 − 卖一量) ÷ (买一量 + 卖一量)，在 −1 到 1 之间，越接近 1 说明买方挂单越厚。把它分成五组（< −0.6、−0.6 到 −0.2、−0.2 到 0.2、0.2 到 0.6、> 0.6），算出每组 5 秒后（seq + 10）中间价平均变动多少跳。

参考答案
SELECT CASE WHEN imb < -0.6 THEN '1 强卖压' WHEN imb < -0.2 THEN '2 卖压'
            WHEN imb <= 0.2 THEN '3 均衡'  WHEN imb <= 0.6 THEN '4 买压'
            ELSE '5 强买压' END AS grp,
       COUNT(*) AS n, ROUND(AVG(move), 3) AS avg_move
FROM (SELECT a.seq,
             (a.bid_vol1 - a.ask_vol1) * 1.0 / (a.bid_vol1 + a.ask_vol1) AS imb,
             ((b.bid1 + b.ask1) - (a.bid1 + a.ask1)) / 2.0 AS move
      FROM ticks a JOIN ticks b ON b.seq = a.seq + 10)
GROUP BY grp ORDER BY grp;
分组快照数5 秒后平均变动（跳）
强卖压2,629−0.292
卖压6,143−0.060
均衡8,552+0.016
买压6,777+0.064
强买压2,889+0.335

失衡越大，价格越可能朝挂单厚的一边走：薄的那一侧更容易被吃光，价格就跳过去。0.3 跳看起来很小，但做市商每手只赚半跳，这个量级足以决定一笔挂单是赚是亏。乘 1.0 是为了让整数相除得到小数。

第 7 周 · 被吃之后 30 秒，做市商赚还是亏三表自连接

先判断每个有成交的快照是谁主动：成交价 ≥ 上一个快照的卖一，算主动买；≤ 上一个快照的买一，算主动卖。主动买时，做市商在卖一卖出；主动卖时，做市商在买一买入。再算这一手在 30 秒后（seq + 60）按中间价盯市赚几跳，分两组求平均。

参考答案
SELECT side, COUNT(*) AS n,
       ROUND(AVG(CASE side WHEN '主动买' THEN last - mid_after
                           ELSE mid_after - last END), 3) AS maker_pnl_30s
FROM (SELECT a.seq, a.last,
             CASE WHEN a.last >= p.ask1 THEN '主动买'
                  WHEN a.last <= p.bid1 THEN '主动卖' END AS side,
             (f.bid1 + f.ask1) / 2.0 AS mid_after
      FROM ticks a
      JOIN ticks p ON p.seq = a.seq - 1      -- 上一个快照
      JOIN ticks f ON f.seq = a.seq + 60     -- 30 秒后
      WHERE a.trade_vol > 0)
WHERE side IS NOT NULL
GROUP BY side;

主动卖（做市商买入）5,724−0.044

成交那一刻，做市商比中间价多赚半跳（0.5）。30 秒后两组都变成了负数：价格平均朝对做市商不利的方向走了半跳多，把价差全吃掉了，这就是逆向选择。卖出那组亏得更多，因为这一天整体在涨。

第 9 周 · 把公式写成函数函数、math

写一个 quote(mid, q, sigma, gamma, k, tau)，返回保留价、总价差、买价、卖价。用专题页演示的默认参数（中间价 3450，库存 2，σ 8，γ 约 0.0039，k 1，剩余 2 小时）检查，应该得到买 3447、卖 3451。

参考答案
w09_quote.py
"""第 9 周：把 Avellaneda-Stoikov 公式写成函数，和专题页的演示对一下数。"""
import math


def quote(mid, q, sigma, gamma, k, tau):
    """返回 (保留价, 总价差, 买价, 卖价)。价格单位都是“跳”（最小变动价位 = 1）。
    mid 中间价；q 库存（多为正）；sigma 每小时波动的跳数；gamma 风险厌恶；
    k 成交衰减；tau 剩余时间（小时）。买价向下、卖价向上取整到整跳。"""
    risk = gamma * sigma ** 2 * tau
    r = mid - q * risk
    d = risk + (2 / gamma) * math.log(1 + gamma / k)
    bid = math.floor(r - d / 2 + 1e-9)
    ask = math.ceil(r + d / 2 - 1e-9)
    if ask <= bid:
        ask = bid + 1
    return r, d, bid, ask


if __name__ == "__main__":
    gamma = 0.001 * 50 ** 0.35          # 专题页“风险厌恶”滑块默认位置，约 0.0039
    r, d, bid, ask = quote(3450, q=2, sigma=8, gamma=gamma, k=1.0, tau=2)
    print(f"保留价 {r:.1f}  总价差 {d:.1f}  买 {bid}  卖 {ask}")   # 应与专题页默认参数的读数一致

    # 自己试：库存从 -5 到 5，报价怎么移动？
    for q in range(-5, 6):
        print(q, quote(3450, q, 8, gamma, 1.0, 2)[2:])

第 10 周 · 第一个回测循环、numpy 数组

每个快照挂买卖各 1 手，库存上限 ±5 手。成交规则：下一个快照的成交价碰到你的价位就算成交（乐观假设，相当于排在队首）。收盘按中间价盯市，盈亏拆成两块：价差捕获（成交价比当时中间价好多少）和库存损益（其余部分）。比较两种报价：固定挂在买一卖一；照搬 A-S 公式（γ 0.01、k 1.5、剩余时间按 1 小时滚动，σ 用数据估计）。

参考答案
w10_w11_backtest.py
"""第 10—11 周：在练习数据上做最简单的做市回测，并拆分盈亏。

假设（都很粗，正是要讨论的地方）：
- 每个快照重新挂单，每次 1 手，库存上下限 ±5 手；收盘按中间价盯市。
- 乐观成交：下一个快照有成交、成交价碰到我们的价位，就算我们成交（相当于排在队首）。
- 保守成交：成交价必须越过我们的价位才算（相当于排在队尾）。真实结果在两者之间。
- 盈亏单位是“跳/手”，乘以合约乘数（比如 10 吨/手 × 1 元/吨）就是元。
"""
import math
import pandas as pd
from w09_quote import quote

df = pd.read_csv("mm_ticks.csv")
df["mid"] = (df.bid1 + df.ask1) / 2
SIGMA = df.mid.diff().std() * math.sqrt(7200)       # 每小时波动多少跳（一小时 7200 个快照）
COLS = ["bid1", "ask1", "bid_vol1", "ask_vol1", "last", "trade_vol", "mid"]


def backtest(df, mode="touch", skew=False, imb_filter=0.0, fill="optimistic",
             cap=5, fee=0.0, gamma=0.01, k=1.5, tau=1.0):
    q, cash, spread_pnl, fills = 0, 0.0, 0.0, 0
    rows = df[COLS].to_numpy()
    for i in range(len(rows) - 1):
        bid1, ask1, bv, av, _, _, mid = rows[i]
        if mode == "as":                                  # 第 10 周：照搬 A-S 公式
            _, _, b, a = quote(mid, q, SIGMA, gamma, k, tau)
            b, a = min(b, ask1 - 1), max(a, bid1 + 1)       # 不越过对手价
        else:                                             # 挂在买一、卖一
            b, a = bid1, ask1
            if skew:                                      # 第 11 周：按库存后撤
                if q > 0: b = bid1 - min(q, 3)
                if q < 0: a = ask1 + min(-q, 3)
        quote_b, quote_a = q < cap, q > -cap
        if imb_filter:                                    # 第 11 周：盘口失衡过滤
            imb = (bv - av) / (bv + av)
            if imb < -imb_filter: quote_b = False
            if imb > imb_filter: quote_a = False
        last, vol = rows[i + 1][4], rows[i + 1][5]
        if vol > 0:
            hit_b = last <= b if fill == "optimistic" else last < b
            hit_a = last >= a if fill == "optimistic" else last > a
            if hit_b and quote_b:
                q += 1; cash -= b; spread_pnl += mid - b; fills += 1
            if hit_a and quote_a:
                q -= 1; cash += a; spread_pnl += a - mid; fills += 1
    total = float(cash + q * rows[-1][6])
    spread_pnl = float(spread_pnl)
    return {"成交手数": fills, "价差捕获": round(spread_pnl, 1), "库存损益": round(total - spread_pnl, 1),
            "合计": round(total, 1), "扣费后": round(total - fee * fills, 1)}


if __name__ == "__main__":
    print("波动率 σ ≈", round(SIGMA, 2), "跳/√小时")
    print("第 10 周 · 固定挂买一卖一：", backtest(df))
    print("第 10 周 · 照搬 A-S：     ", backtest(df, mode="as"))
    for fill in ["optimistic", "conservative"]:
        print(f"\n第 11 周 · {'乐观' if fill == 'optimistic' else '保守'}成交，手续费 0.2 跳/手")
        for name, kw in [("固定挂买一卖一", {}), ("+ 按库存后撤", {"skew": True}),
                         ("+ 盘口失衡过滤", {"imb_filter": 0.6}), ("两者都加", {"skew": True, "imb_filter": 0.6})]:
            print(f"  {name:<10}", backtest(df, fill=fill, fee=0.2, **kw))

固定挂买一卖一5,355+2,714.5−1,534.0+1,180.5
照搬 A-S243+260.5−216.0+44.5

数据估出的波动率约 9.1 跳/√小时。按这组参数，A-S 的总价差约 2.2 跳，买价向下、卖价向上取整之后，报价总是比买一卖一远一跳，所以几乎排不上成交。价差只有一跳的市场，连续价格的公式不能直接用，这正是 Cartea 第 10 章要讲 at-the-touch 做市的原因。

第 11 周 · 改进策略，换成交假设函数参数、对比实验

在“固定挂买一卖一”上加两个改进：按库存后撤（有多头时买价往后撤，撤几跳等于库存手数，最多 3 跳；空头反之）；盘口失衡过滤（失衡低于 −0.6 时不挂买单，高于 0.6 时不挂卖单）。四个版本分别在乐观成交和保守成交（成交价必须越过你的价位）下运行，每手扣 0.2 跳手续费。代码和第 10 周是同一个文件。

一、成交假设决定结论。同一个策略，乐观假设下赚 1,180 跳，保守假设下亏 828 跳。保守假设下只有价格穿过你的价位才成交，而价格穿过时往往还会继续走，所以每一笔都是被逆向选择的那一笔。真实结果在两者之间，取决于你在队伍里排第几，这也是做市回测必须模拟排队位置的原因。

二、手续费能吃掉大部分利润。固定挂买一卖一成交 5,355 手，0.2 跳的手续费就扣掉 1,071 跳，只剩 110 跳。这就是交易所手续费减收对做市商这么重要的原因。

三、库存控制最有用。按库存后撤把库存损益从 −1,534 压到 −490；盘口失衡过滤在乐观假设下作用不大，在保守假设下把亏损减少了八成。两者合用效果最好。
