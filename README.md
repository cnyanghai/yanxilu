# 研习录

个人学习知识库：把学习计划讨论、读书精读和复习痕迹整理成一个可以长期积累、随时回看、也能留给后来者的网页。

直接打开 `index.html` 即可阅读；开启 GitHub Pages 后，任何人都能在线访问。

## 内容

- **五个学习方向**：地缘政治与战争、CFA 级金融知识、上市公司与行业分析、经济周期、期货与大宗商品。每个方向按阶段排好书目、科目和实践任务。
- **精读模块**：目前有《大国政治的悲剧》（米尔斯海默），包括导读、十章精读（核心论点、关键概念、历史案例、思考题、批注）、25 张概念卡、争鸣与延伸阅读、冲突分析框架。
- **精读稿**：按论证单元重建原书的推理、例证和对反驳的回应（用自己的话，不摘录原文），支持一句话 / 提要 / 全文三档阅读，正文嵌入自测题。已完成第二章。
- **假设开关与论证地图**：关掉任一基本假设，看推论链在哪里断开；全书论证树连到精读稿的对应单元。
- **每日课表**：第一阶段 12 周（2026-10-12 起），SQL、Python、CFA 一级、英语、地缘政治，每天 1.5–2 小时。每天早上 7 点（北京时间）推送当天讲义，晚上 9 点打卡，没学完的课下次接着学。说明见 `study/README.md`。
- **学习足迹**：每次学习留下的记录。
- **复习**：概念卡按 1、3、7、16、35 天的间隔重复复习。

## 两个版本

| 版本 | 进度与批注保存在哪里 |
| --- | --- |
| claude.ai 上的 Artifact（主用版） | 云端记录，跨设备同步，只有所有者能修改 |
| 本仓库的 `index.html`（公开版） | 显示最近一次同步的学习记录；访客的修改只存在自己的浏览器里 |

每次在对话里更新研习录后，Claude 会把云端记录导出到 `src/data.js` 的 `YXL_RECORD`，重新生成 `index.html` 并推送到这里，所以提交历史就是完整的学习轨迹。

## 文件结构

```
src/page.html   页面结构与样式
src/data.js     内容数据：路线图、精读模块（YXL_LIB）和学习记录快照（YXL_RECORD）
src/deep-*.js   各书的精读稿、自测题、假设开关、论证地图
src/plan.js     每日课表：一周时段安排与各科课程顺序
study/          课表进度（progress.json）、每日讲义（daily/）和推送、打卡脚本
src/app.js      页面逻辑
build.py        合成 index.html（公开版）与 dist/artifact.html（claude.ai 版）
```

修改内容后运行 `python3 build.py`。

## 新增一本书的精读模块

1. 在 `src/data.js` 的 `books` 里加一项，结构照抄 `tragedy`。
2. 在对应方向的条目上加 `module: "<书的 id>"`。
3. 运行 `python3 build.py`。
