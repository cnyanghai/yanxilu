# 邮差（代号 yanxilu）

> 2026-11-08 起产品名改为「邮差」；仓库、目录、Baba 路由名 yanxilu 不变，文档里 2026-11-08 以前的「研习录」指的是同一个东西。

> 独立 App「邮差」（2026-11-08 起冻结，不再推进）：同一份代码的另一个入口 `youchai/`（PWA），只有首页大门、书架、档案架、笔记本，墓园场景固定；线上 `baba.wogucloud.cn/youchai/`，手机浏览器「添加到主屏幕」即装。

个人学习知识库：把学习计划讨论、读书精读和复习痕迹整理成一个可以长期积累、随时回看、也能留给后来者的网页。

直接打开 `index.html` 即可阅读；开启 GitHub Pages 后，任何人都能在线访问。

## 方向（2026-11-11 定）

邮差是一间自己的学习空间，也是以后别人可以来逛的地方。三件家具各管一件事：

- **书架**：立体的一面书墙。比封面墙集约，一眼知道有多少书、读了多少。
- **档案架**：看过的网页一键变成牌，收进卡包；拆包、整理、回看要让人有兴趣。
- **笔记本**：随手记、读书看视频的体会、订阅到期的提醒。

以后：一排书、一包牌、一本笔记可以整个分享（免费或收费；分享的是书单、顺序、自己写的东西和原文链接，不是书的文件和文章正文）；像任务公告板的社交；每个人的空间不一样，值得逛。气质不要正式，要有游戏感。

怎么做（依据在 `STATUS.md`「已定决策」）：

- 立体做到「物件」这一层：书架、书、卡包、牌、本子是真的三维物件，有光有影、能抽能拆；家具以后要能摆进一间固定视角的房间；能走的世界（yanxilu-world 仓库）先放下。
- 先用行为定三个瞬间，各做一个能动的灰盒样机，在手机上按手感过门，都过了再选外观：**一眼看全**（打开就看到整面书架，任何一本能一下抽出来）、**拆包**（几秒钟的仪式，拆完牌在手里，能快进）、**进门**（点开别人的链接三秒看懂他在学什么，一个动作带走一排）。其余的读、写、搜保持又快又素。
- 现有纸模版原样留作每天用的工具，外观不再加工。样机放在 `lab/`，线上 `/lab/`。
- 2026-11-13 三个瞬间都过了门，外观定「旧书房」（暗处一盏暖灯、胡桃木架子、布面烫金的书，没读的包着牛皮纸捆麻绳，和没拆的邮包是同一种东西）。现在按门把它做到成品，门和进度在 `lab/README.md`。
- 2026-11-14 立体书房接上了账号：主站多一页 `#shufang`（线上 `https://baba.wogucloud.cn/#shufang`），把书架那一页样机嵌进去，架上是账号里真的书、牌盒、牌、本子；抽出来再点一下就进去（阅读器、书页、本子页），按返回回到书房。这一步只读，写的事（记一笔、放书、立盒、拆包）还在纸模版做；纸模版还是首页。说明见 `lab/README.md`「接上账号」一节。
- 2026-11-15 两个版面分开（用户定叫法）：**第一版**是纸模的直板版面（顶上邮差、书墙 / 档案架 / 笔记本架三块数字砖），**第二版**是实木书架的书房（`#shufang`）。两版都留着、互不串：在第二版里翻开本子、拆邮包、看书，开的是第二版自己的页；只在第二版工具纸的「换到第一版」和第一版页底的「换到第二版」明着换。同一天第二版的三件家具改成固定大小（东西少也是一座装满一屏的架子，一件件往上添），整体调亮。说明见 `lab/README.md`「两个版面分开、架子固定、调亮」。
- 不做：照着一张好看的参考图直接改主线（新参考进待办）；现在不做账号体系、支付和平台。

## 内容

- **首页 · 线网图**：每门课、每本书是一条线，一课（一章、一周）是一站；横竖交叉的换乘站表示两条线用到同一块知识，方块地标是讨论和查到的资料（不算进度），虚线是规划中的第二阶段。首页上方是“今日路线”，可选保底、标准、加开三档；下方“各线到站”按时刻表算出每条线正点、晚点还是早到。布局在 `src/metro.js`。
- **五个学习方向**：地缘政治与战争、CFA 级金融知识、上市公司与行业分析、经济周期、期货与大宗商品。每个方向按阶段排好书目、科目和实践任务。
- **精读模块**：
  - 《大国政治的悲剧》（米尔斯海默）：导读、十章精读（核心论点、关键概念、历史案例、思考题、批注）、25 张概念卡、争鸣与延伸阅读、冲突分析框架。
  - 《涛动周期录》（周金涛）：第五次康波时间轴（各章所处年份可点开）、四周期嵌套图（可勾选叠加看“共振”）、七章导读与 48 篇报告清单（附阅读提示）、22 张概念卡、“当时的判断，后来怎样”对照表、四周期定位清单、论证地图，第七章“周期真实义”精读稿。
- **精读稿**：按论证单元重建原书的推理、例证和对反驳的回应（用自己的话，不摘录原文），支持一句话 / 提要 / 全文三档阅读，正文嵌入自测题。已完成《大国政治的悲剧》第二章、《涛动周期录》第七章。
- **假设开关与论证地图**：关掉任一基本假设，看推论链在哪里断开；全书论证树连到精读稿的对应单元。
- **每日课表**：第一阶段 12 周（2026-10-12 起）。每天先走英语·电影线（90 分钟），再学两门课（SQL、Python、CFA 一级、地缘政治、周复盘按星期轮换）。讲义一课一个文件（`study/lessons/`），每天早上 7 点（北京时间）写好当天要用的讲义和一张路线单（`study/daily/`），晚上 9 点打卡，没学完的课下次接着学同一个文件。说明见 `study/README.md`。
- **课程页**：每条线一个页面（`#c-sql`、`#c-cfa` 等）：全部课程、每课状态、已写好的讲义、经过的换乘站和用得上的研究资料。
- **电影跟读播放器**（`#c-film`）：《当幸福来敲门》按字幕切成 36 段，每天一段。用自己的片源和字幕文件（只在浏览器里打开，不上传），逐句听、循环、放慢、遮字幕或只看首字母和中文提示、跟读停顿、录音对比、标记背熟；云端版可以让 Claude 讲解一句台词。只记“第几段第几句背熟”，不存台词。
- **学习足迹**：每次学习留下的记录。
- **复习**：概念卡按 1、3、7、16、35 天的间隔重复复习。
- **书墙与电子书**（书架，2026-11-09 起纸模）：一块牛皮纸板，层板按行重复，不分领域，书是一片片立着的纸，书名印在竖的米白签上，在读的露一条书签，挂了电子书的有一点铜钉；最后一格「放一本书」直接选 PDF 或 EPUB（书名从文件名带出，保存即上传），也可以先只填书名。右边的书立放拿起来的那本：封面朝外露书口的纸书、书名作者、读到哪、「接着读」或「挂上 PDF 或 EPUB」、几条划线；改书名与拿下收在「更多」。给书挂上 PDF 或 EPUB 后在页面里读：读到哪自动记进阅读进度；选中文字可以划线、写批注，全书的划线和批注在侧栏里。公开版的电子书只存在自己的浏览器里；服务器版单本最多 600 MB。书墙不再有筛选、布置、图例、精读入口；旧的场景（拱形书柜、墓园宽柜）、装帧库（布面、烫金、维多利亚、秘典、老书皮）、摆件、英语片盒与 CFA 函套的代码和素材还在仓库里（`vendor/scene/`、`vendor/covers/`、`docs/bookcase-production.md`、`docs/cover-masters.md`），这轮不在书墙上。
- **档案架**（书架，2026-11-09 起纸模）：一块牛皮纸板加层板，不分领域；一个课题一个牌盒，同向立在板上一排，盒厚等于件数，盒面是领域大字、卷号、盒名，同一层赤陶与黑卡交替；没装盒的剪报是层板尽头的一叠牌（有没拆的牌背朝上），收件匣也是一叠牌，最后一格「＋ 新盒」。点一盒在右边一栏（手机整屏）摊开：卷号、盒名、要回答的问题，盒子立着盖子翻开，牌摊在旁边，没读的牌背朝上（黑卡铜字领域大字），读过的牌面朝上（米白：类型一字签、标题、来源与日期与分钟、为什么存，写过批注的有铜印）；「现在的答案」是便签，牌册与来龙去脉折叠，备考与改删撤在底下。自己新立档案盒（盒名、问题、领域、状态、备考，集合 `aboxes`）、改和删；自带的盒子可以撤下、放回（`aboxoff`）。没有在做 / 要年更 / 已结卷的筛选与状态签。
- **数据专题**：[中美消费与人口](reports/consumption-population.html)，2000 年以来中美居民消费率、消费结构对比与中国人口年龄结构（每五年节点、五岁组人口金字塔），配图、数据表和来源。全部序列整理成长表 CSV（`reports/data/consumption-population.csv`），可直接导入数据库练习 SQL。
- **数据专题**：[中美日财富存量](reports/wealth.html)，居民存款、股票、债券、期货、黄金储备、住房市值与住房、汽车保有量的三国对比（2025 年末），长表 CSV 在 `reports/data/wealth.csv`。
- **全站搜索**：顶栏放大镜或 Ctrl/Cmd + K，一个框搜遍书、剪报、档案盒、讲义、精读章、专题、足迹和划线，回车直达。
- **笔记本架**（书架，2026-11-09 起纸模、多本）：一块牛皮纸板一层层板，本子封面朝外同向立着、右边露书口、页越多越厚、封面贴米白签写本名与页数；最后「＋ 新本子」。随手本一天一页：左页当月日历（写过的日子有墨点）和最近几页，右页正文；主题本自己立（本名、六色封面、一句说明），翻开左页是页目录与「＋ 新一页」，右页标题可改、正文点纸面编辑、停笔自动保存、「撕掉这一页」，撕光了才能删本。顶栏「记一笔」（桌面快捷键 N）落下一张纸条，有主题本时可选记到随手本今天或某本的最新一页。地址 `#notes` 今天、`#notes-2026-11-03` 那一天、`#nb-<本子>`、`#np-t-<页>`。全站搜索能搜到笔记。数据在 `pages`（随手本 `np-d-日期`，主题本的页 `np-t-…`）和 `nbooks`，和三维版共用；正文只存自己的 Baba 账号或浏览器，不进仓库。设计稿 `docs/notebook-design.md`。
- **摘抄册**（书架）：所有书和剪报里的划线、批注按来源抄成一册，可按领域、颜色筛，点一条回到原处；能打印或存成 PDF。
- **晚间仪式**（打卡 · 盖章）：首页今日路线的终点站整页展开当天几站，点亮学完的、写一句话、盖下红章，足迹和线网立刻跟着走；写的是 Baba 数据库的 `study.progress` 文档，页面把它和 `study/progress.json` 按天合并。概念卡到期时首页会出现复习入口（1/3/7/16/35 天间隔）。
- **手机装成 App**：网站带 manifest 和 Service Worker（`src/sw.js`，`build.py` 盖版本号生成 `sw.js`），手机上「添加到主屏幕」离线也能打开；`/api/` 和电子书文件从不缓存。
- **剪报**（档案架，服务器版）：在知乎（也支持微信公众号和一般网页）看到好的回答或文章，点浏览器书签栏里的「收进邮差」，弹出的小窗里选放到哪（某个领域的剪报夹、某个档案盒，或者当场新立一盒）、写一句为什么存，就上了档案架；先选中一段就只存那一段。分了领域还没装盒的剪报插在那一格的剪报夹里，没分领域的进收件匣，装进盒的算盒里的一件（牌面上的一字签是「剪」）。手机上把知乎 App「分享 → 复制链接」得到的文字粘进剪报框先存链接，回电脑再补全文。剪报在邮差的阅读器里读，能划线、批注、记读到哪；正文存在自己的 Baba 账号里（`clips` / `clipbody`），不进本仓库。
- **卡牌与卡包**（档案架）：盒里的每一件、夹里的每一篇都是一张牌。没读的牌背朝上（黑卡、铜色双框、领域大字、卷号），读过的牌面朝上（米白卡纸）。点一张牌翻过来放大，翻面就是整篇文章（阅读器）。剪报夹与收件匣是一叠还没拆的牌，一条米白封条写「封」和日子，点一下拆封，封条崩开、牌飞出来落成一排；拆过的缩成小小一摞当夹子。牌拖到下面的盒子上就装盒，桌上也能新立一盒；「牌册」折叠着目录表。拆封（或第一次翻开）记在剪报的 `seen` 字段里。
- **知识专题**：[期货做市商](reports/market-making.html)，准入条件、盈亏方程（可切换情景的示意账）、七块核心知识、可调参数的 Avellaneda-Stoikov 报价演示、跨期与对冲、常见亏法、学习路线与书单、自测题。
- **知识专题**：[做市商研习计划](reports/market-making-plan.html)，12 周、每周一读一做，与每日课表第一阶段同步；附一天的模拟 tick 练习数据（`reports/data/mm_ticks.csv`，生成脚本 `make_mm_ticks.py`）、两轮纸上做市、SQL 与 Python 习题，参考答案在 `reports/data/mm_exercises/`。页面里的代码由构建脚本从这些文件插入。

### 服务器版怎么跑

讲义、路线单、课表进度在构建时打包进页面，推送到 main 后服务器几分钟内自动更新，不用部署。

Baba 英语（Next.js）的首页 `/` 直接读 `YXL_DIR/server/index.html`（服务器上一份本仓库的克隆，cron 定时 `git pull`），`/vendor/`、`/reports/` 也从这份克隆里读，所以研习录更新只要推送到这里，不用重新部署 Baba。
`server/index.html` 和 `index.html` 是同一个页面，只是前面多一段 `src/server.js`：它仿照 claude.ai 的运行时接口（db / user / assets），背后换成 Baba 的 `/api/yxl/*`：

- `GET /api/yxl/state`：当前账号的全部记录；`PUT / DELETE /api/yxl/doc`：写一条、删一条；`POST /api/yxl/docs`：整批导入（claude.ai 版导出的记录文件）
- `POST /api/yxl/files`、`GET / DELETE /api/yxl/files/<id>`：电子书文件（页面里的地址仍是 `/_blob/<id>`，由 Baba 转过去）
- `GET /api/yxl/english`：Baba 上每部片几集、多少句、看到哪一句、累计时长，生词本里各状态的数量

英语一层：片盒的进度条、在学 / 学完由 Baba 的观看进度算出来；Baba 后来加的片子也会自动摆上书架。点「接着学」在浮层里打开 Baba 的逐句学页面，接着上次那一句；生词本、学习进度也在浮层里打开，关掉浮层就刷新。

每次在对话里更新研习录后，Claude 会把云端记录导出到 `src/data.js` 的 `YXL_RECORD`，重新生成 `index.html` 并推送到这里，所以提交历史就是完整的学习轨迹。

```
build.py        合成 index.html（公开版）、dist/artifact.html（claude.ai 版）、server/index.html（服务器版），以及 reports/ 下的专题页
```

修改内容后运行 `python3 build.py`。

## 新增一本书的精读模块

1. 在 `src/data.js` 的 `books` 里加一项，结构照抄 `tragedy`。书的 id 与路线图条目的 id 相同。
2. 在对应方向的条目上加 `module: "<书的 id>"`；想放到总览的“正在精读”，把 id 加进 `focus` 数组。
3. 精读稿、自测题和论证地图写在 `src/deep-<书的 id>.js`。
4. 运行 `python3 build.py`。

可选字段（照抄 `zhoulu`）：`subtitle` 副书名；`labels.cases` 改“历史案例与要点”的标题；章节里的 `reports` 列出收录的文章；`timeline` 时间轴；`nest` 周期嵌套图；`scorecard` 判断对照表；`framework.foot` 分析清单的用法说明。精读稿单元的 `practice` 可以写 `{ p: "framework", label: "…" }`，链到对应的练习。
