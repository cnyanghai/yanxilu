## 本课目标

1. 会从 Anaconda 打开 Jupyter Notebook，新建、改名、保存一个笔记本。
2. 分清两种单元格：**Code**（代码）和 **Markdown**（文字说明），会用快捷键运行。
3. 会用 `print()` 输出、用 `#` 写注释、把 Python 当计算器用。

## 讲解一：Anaconda、Jupyter、Python 是什么关系

- **Python**：编程语言本身。
- **Anaconda**：一个“工具大礼包”，装好了 Python 和几百个常用库（pandas 处理表格、openpyxl 读写 Excel 等），省得一个个装。
- **Jupyter Notebook**：在浏览器里写 Python 的“笔记本”。一份笔记本（`.ipynb` 文件）由很多**单元格**组成，每格可以单独运行、马上看到结果——很适合边学边试，也适合一步步处理一份 Excel：读进来 → 看一眼 → 清洗 → 再看一眼 → 导出。

可以这样类比：Python 是发动机，Anaconda 是整辆车，Jupyter 是驾驶座。

## 讲解二：打开并建好今天的笔记本（约 8 分钟）

1. 开始菜单搜 **Anaconda Navigator** → 在 Jupyter Notebook 那格点 **Launch**（也可以开始菜单直接搜 *Jupyter Notebook*）。浏览器会打开一个文件列表页，背后还有一个黑色窗口——**别关它**，关了 Jupyter 就停了。
2. 进到练习文件夹（建议 `D:\研习录\python`）。
3. 右上角 **New → Python 3 (ipykernel)**，点左上角的 *Untitled*，改名为 `01_第一个程序`。
4. 保存：`Ctrl + S`。Jupyter 也会每隔几分钟自动保存。

**两种模式**（Jupyter 最容易困惑的地方）：

| 模式 | 怎么进入 | 单元格左边框 | 这时按键的作用 |
|---|---|---|---|
| 编辑模式 | 在单元格里点一下，或按 `Enter` | 绿色（新版为蓝色、有光标） | 打字 |
| 命令模式 | 按 `Esc` | 蓝色、没有光标 | 按单个字母操作整个单元格 |

**常用快捷键**（先记前四个）：

| 快捷键 | 作用 |
|---|---|
| `Shift + Enter` | 运行当前格，跳到下一格（最常用） |
| `Ctrl + Enter` | 运行当前格，停在原地 |
| `Esc` 然后 `B` | 在下方插入新单元格（Below） |
| `Esc` 然后 `M` / `Y` | 把单元格切换成 Markdown / Code |
| `Esc` 然后 `D D` | 删除单元格（按两次 D） |
| `Esc` 然后 `Z` | 撤销删除 |

单元格左边的 `In [3]:` 表示这是第 3 个被运行的格；正在运行时显示 `In [*]:`。

## 讲解三：第一个程序

依次把下面每段放进一个单独的单元格，`Shift + Enter` 运行。

**单元格 1：输出一句话**

```python
print("hello, 研习录")
```

- `print()` 是一个**函数**：括号里放什么，就把什么显示出来。
- 文字要用**英文引号**包起来，单引号 `'...'` 和双引号 `"..."` 都行，前后要一致。被引号包起来的文字叫**字符串**（string）。

**单元格 2：注释和多行输出**

```python
# 井号后面是注释，Python 不执行，用来写说明
print("第一行")
print("第二行")   # 注释也可以写在代码后面
print("姓名：", "赵小一", "金额：", 1200)
```

输出：

```
第一行
第二行
姓名： 赵小一 金额： 1200
```

`print()` 里可以放好几样东西，用逗号隔开，输出时自动用空格连起来。注意 `1200` 没加引号——它是数字，不是文字。

**单元格 3：把 Python 当计算器**

```python
print(1200 + 800)        # 加
print(1500 - 600.5)      # 减
print(950 * 12)          # 乘：用 * 不是 ×
print(6250.5 / 6)        # 除：用 / 不是 ÷，结果总是小数
print(17 // 5, 17 % 5)   # 整除取商、取余数
print(1.05 ** 3)         # 乘方：1.05 的 3 次方
```

输出：

```
2000
899.5
11400
1041.75
3 2
1.157625
```

**单元格 4：单元格最后一行的值会自动显示**

```python
1.10 * 0.95 * 1.08 - 1
```

不写 `print`，Jupyter 也会显示 `0.12860000000000005`。末尾那串 `0000000005` 是计算机存小数的正常误差，不是算错了。想要整齐，用 `round(数字, 位数)`：

```python
round(1.10 * 0.95 * 1.08 - 1, 4)
```

结果 `0.1286`——正好是今天 CFA 课里多期持有期收益率的算法，以后算 CFA 题可以直接用 Jupyter 验算。

**单元格 5：Markdown 单元格写笔记**

新建一格，按 `Esc` 再按 `M` 切成 Markdown，输入：

```markdown
# 第 1 课：第一个程序
- `print()` 输出
- `#` 写注释
- **Shift + Enter** 运行
```

运行后变成排好版的标题和列表。双击可以再改。养成习惯：每个笔记本开头写一格 Markdown，说明这个笔记本是干什么的。

**单元格 6：先尝一口——三行代码生成并读回一个 Excel**

```python
import pandas as pd

df = pd.DataFrame({"姓名": ["赵小一", "钱小二", "孙小三"], "金额": [1200, 800, 1500]})
df.to_excel("01_试一试.xlsx", index=False)
pd.read_excel("01_试一试.xlsx")
```

运行后显示一张三行的小表，文件列表页里多了 `01_试一试.xlsx`，可以用 Excel 打开看看。今天**不要求看懂**这几行——第 13 课左右学 pandas 时会逐行讲。先知道：以后成千上万行的 Excel 清洗、比对，就是这样几行代码完成的。

（如果报 `No module named 'openpyxl'`：新建一格运行 `%pip install openpyxl`，然后菜单 *Kernel → Restart*，再从单元格 6 重新运行。）

## 讲解四：看懂报错

故意运行下面这格：

```python
print("hello)
```

会看到类似：

```
  Cell In[7], line 1
    print("hello)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

读报错的顺序：**先看最后一行**（错误类型 + 说明），**再看 line 几和 `^` 指的位置**。`SyntaxError` 是语法错误，`unterminated string literal` 的意思是“字符串没有结束”——少了后半个引号。

最常见的三种：

| 报错 | 原因 | 例子 |
|---|---|---|
| `SyntaxError` | 语法写错：少引号、少括号、用了中文标点 | `print（"hi"）` |
| `NameError: name 'xxx' is not defined` | 用了一个 Python 不认识的名字：拼错、大小写错、文字忘加引号 | `Print("hi")`、`print(hello)` |
| `TypeError` | 类型不对，比如文字和数字直接相加 | `"金额" + 1200` |

Python **区分大小写**：`print` 对，`Print` 错。

## 常见错误

- **关掉了黑色窗口**：Jupyter 停止运行，网页上出现 *Kernel 连接断开*。重新从 Anaconda 打开即可，笔记本已保存的内容还在。
- **中文标点**：`（）`、`“”`、`，` 都会导致 `SyntaxError`。代码里的符号一律英文半角，引号**里面**的中文没关系。
- **在命令模式下打字**：按了一串字母却没输入进去，反而插入、删除了单元格。先 `Esc` 再按 `Z` 撤销，然后点进单元格再打字。
- **单元格停在 `In [*]` 不动**：上一格还没跑完或卡住。点工具栏的 ■（Interrupt），不行就 *Kernel → Restart*。
- **重启后报 `NameError`**：重启会清空内存，前面单元格定义过的东西没了。从上往下重新运行一遍（菜单 *Run → Run All Cells*，旧版是 *Cell → Run All*）。
