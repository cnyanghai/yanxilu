## SQL 小测（5 题）

1. 把下面四样东西和 Excel 里的概念对上：数据库、表、行、列。
2. 报销金额这一列，建表时应该用哪种类型？日期在 SQLite 里通常怎么存？
3. 下面这句为什么会报错？

   ```sql
   CREATE TABLE meal_claims (
       claim_no INTEGER PRIMARY KEY,
       name     TEXT,
       amount   REAL,
   );
   ```

4. 写一句查询：从 `travel_claims` 里只取姓名和金额两列，结果里列名显示为“姓名”“金额”。
5. 插入一行时报 `UNIQUE constraint failed: travel_claims.claim_no`，说明发生了什么？这在核查工作里有什么用？

<details>
<summary>SQL 小测答案</summary>

1. 数据库 ↔ 整个工作簿（SQLite 里是一个 `.db` 文件）；表 ↔ 一个工作表；行 ↔ 一行记录；列 ↔ 一列加列标题。
2. 金额用 `REAL`（小数）。日期用 `TEXT`，写成 `'2026-04-08'` 这种“年-月-日”格式，排序和比较都不会乱。
3. 最后一列 `amount REAL` 后面多了一个逗号。最后一列后面不加逗号。
4.
   ```sql
   SELECT name AS 姓名, amount AS 金额 FROM travel_claims;
   ```
5. 插入的报销单号已经存在。单号是主键，不能重复，所以“同一张单子登两次”在录入时就被挡住了，不用等人眼发现。

</details>

## Python 小测（5 题）

1. 在 Jupyter 里，`Shift + Enter` 和 `Ctrl + Enter` 有什么区别？
2. 下面这格输出什么？

   ```python
   print("合计：", 300 + 450)
   ```

3. `17 // 5` 和 `17 % 5` 分别等于多少？
4. 运行 `Print("hi")` 会报哪种错？为什么？
5. 下面这格的结果是多少？（先心算，再到 Jupyter 里验证）

   ```python
   round(1.08 * 0.95 - 1, 4)
   ```

<details>
<summary>Python 小测答案</summary>

1. 两者都运行当前单元格；`Shift + Enter` 运行后跳到下一格，`Ctrl + Enter` 运行后停在原地。
2. `合计： 750`。逗号隔开的两样东西之间自动加一个空格。
3. `3` 和 `2`。`//` 是整除取商，`%` 是取余数（17 = 5 × 3 + 2）。
4. `NameError: name 'Print' is not defined`。Python 区分大小写，函数名是小写的 `print`。
5. `0.026`。1.08 × 0.95 = 1.026，减 1 得 0.026——这正是“先涨 8% 再跌 5%”的两期持有期收益率 2.6%。

</details>

## CFA 小测（5 题，仿一级三选一）

**1.** "Lin could earn 5% by putting her savings in a one-year deposit, but she keeps the cash at home instead." The 5% is best described as a(n):

A. required rate of return.
B. opportunity cost.
C. discount rate.

**2.** Given: real risk-free rate 1.8%, inflation premium 2.4%, default risk premium 1.5%, liquidity premium 0.6%, maturity premium 0.9%. The required return on the bond is closest to:

A. 4.2%
B. 5.7%
C. 7.2%

**3.** Two bonds from the same issuer have the same maturity and the same terms. The heavily traded bond yields 6.1%, and the thinly traded bond yields 6.6%. The difference is most likely explained by the:

A. liquidity premium.
B. maturity premium.
C. default risk premium.

**4.** An investor buys a share at $50.00, receives a dividend of $1.50, and sells the share at $53.00. The holding period return is closest to:

A. 3.0%
B. 6.0%
C. 9.0%

**5.** A fund returns 10%, −10%, and 8% in three consecutive years. The three-year holding period return is closest to:

A. 8.00%
B. 6.92%
C. 2.31%

<details>
<summary>CFA 小测答案与解析</summary>

1. **B**。关键词 *could earn … instead*：把钱放在家里，放弃了本可以赚的 5%，是机会成本。
2. **C**。1.8 + 2.4 + 1.5 + 0.6 + 0.9 = 7.2%。B 只加了前三项，漏了流动性和期限溢价；A 只是名义无风险利率（1.8 + 2.4）。
3. **A**。发行人相同（违约风险一样）、期限相同（期限溢价一样），差别只能来自“好不好卖”——流动性溢价，差 0.5%。
4. **C**。(53.00 − 50.00 + 1.50) ÷ 50.00 = 4.50 ÷ 50 = 9.0%。B 漏了股息（3 ÷ 50 = 6%）；A 只算了股息收益率（1.5 ÷ 50 = 3%）。
   计算器：`53 − 50 + 1.5 =` → `÷ 50 =` → `0.09`
5. **B**。1.10 × 0.90 × 1.08 − 1 = 1.0692 − 1 = 6.92%。A 是直接相加（10 − 10 + 8）；C 是把 6.92% 除以 3 的错误“年均”算法。
   计算器：`1.1 × 0.9 × 1.08 − 1 =` → `0.0692`
   直觉检查：先涨 10% 再跌 10% 不是回到原点，而是 1.1 × 0.9 = 0.99，亏了 1%。

</details>

## 小实战：培训费报销和签到表比对（25 分钟）

**场景**：一个虚构单位开了三期内部培训，每期按人收培训费，由个人先垫付、再报销。你手上有两份材料：《培训费报销台账》（8 笔）和《培训签到表》（6 条）。要找出“报了这一期的培训费，这一期却没有签到”的记录，算出涉及金额和占比。

只用本周学过的东西：`CREATE TABLE`、`INSERT`、`SELECT`、`COUNT(*)`、`AS`，加上 Python 的 `print` 和四则运算。

### 第一步：建表加数据（SQL，DB Browser 里运行）

打开 `practice.db` → **Execute SQL** → 粘贴整段 → `Ctrl + Enter` → **Write Changes**。

```sql
-- 周复盘 1：培训费报销台账与签到表（数据全部虚构）
DROP TABLE IF EXISTS training_claims;
DROP TABLE IF EXISTS sign_in;

CREATE TABLE training_claims (
    claim_no     INTEGER PRIMARY KEY,   -- 报销单号
    emp_no       TEXT,                  -- 工号（虚构格式）
    name         TEXT,                  -- 姓名
    course_date  TEXT,                  -- 培训日期（哪一期）
    fee          REAL                   -- 报销的培训费（元）
);

INSERT INTO training_claims (claim_no, emp_no, name, course_date, fee) VALUES
    (3001, 'E-0201', '甲小禾', '2026-05-06', 800),
    (3002, 'E-0202', '乙小苗', '2026-05-06', 800),
    (3003, 'E-0203', '丙小松', '2026-05-06', 800),
    (3004, 'E-0204', '丁小竹', '2026-05-13', 1200),
    (3005, 'E-0202', '乙小苗', '2026-05-13', 1200),
    (3006, 'E-0205', '戊小梅', '2026-05-20', 650),
    (3007, 'E-0203', '丙小松', '2026-05-20', 650),
    (3008, 'E-0206', '己小兰', '2026-05-20', 650);

CREATE TABLE sign_in (
    sign_id      INTEGER PRIMARY KEY,   -- 签到序号
    emp_no       TEXT,
    name         TEXT,
    course_date  TEXT
);

INSERT INTO sign_in (sign_id, emp_no, name, course_date) VALUES
    (1, 'E-0201', '甲小禾', '2026-05-06'),
    (2, 'E-0203', '丙小松', '2026-05-06'),
    (3, 'E-0204', '丁小竹', '2026-05-13'),
    (4, 'E-0202', '乙小苗', '2026-05-13'),
    (5, 'E-0205', '戊小梅', '2026-05-20'),
    (6, 'E-0206', '己小兰', '2026-05-20');
```

### 第二步：按顺序完成 5 个任务

1. **先数笔数**：分别数出两张表各有几行。台账应为 8 笔，签到应为 6 条。对不上就先检查脚本有没有完整运行。
2. **取出比对用的列**：从台账取 `emp_no, name, course_date, fee`，列名显示为“工号”“姓名”“培训日期”“培训费”；从签到表取 `emp_no, name, course_date`，列名同样用中文。
3. **试一试主键**：有人说 3005 这笔“漏登了”，要求再登一次（3005，E-0202，乙小苗，2026-05-13，1200）。执行这句 `INSERT`，看会发生什么，用一句话写下结论。
4. **目测比对**：把第 2 题的两个结果并排看，逐笔核对台账里的每一笔，**工号和培训日期都对得上**的才算签到了。找出没有对应签到的报销单号。注意：只看名字的话会漏掉谁、错判谁？
5. **算金额和占比（Python，Jupyter 里运行）**：用 `print` 输出三行——台账培训费合计、疑点金额合计、疑点金额占合计的百分比（保留两位小数）。数字从第 4 题的结果来，算式让 Python 算，不要手算后再抄。

### 常见错误

- 两张表都叫 `course_date`，取列时别把签到表的日期当成台账的日期——分开两句查询，先跑一句看清楚再跑下一句。
- 第 3 题报错后，别以为是自己写错了：读一读报错最后一行。
- 第 5 题百分比要先除再乘 100，括号别漏：`(疑点) / 合计 * 100`。

**预告**：学到 JOIN 以后，第 4 题一句话就能筛出来（现在不要求看懂）：

```sql
SELECT t.claim_no, t.name, t.course_date, t.fee
FROM training_claims t
LEFT JOIN sign_in s
  ON t.emp_no = s.emp_no AND t.course_date = s.course_date
WHERE s.sign_id IS NULL;
```
