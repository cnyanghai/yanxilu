# 每日课表：运行说明

这份说明写给每天早晚自动运行的两个定时任务，也方便以后自己查。课程安排在 `src/plan.js`，进度在 `study/progress.json`，讲义一课一个文件放在 `study/lessons/`，每天的路线单放在 `study/daily/`。

## 进度怎么走

- 课程按顺序推进，不和日期绑死。`progress.json` 的 `next` 记着每科下一课的序号（从 0 开始）。
- 早上推送时，按“周几的时段安排 + 各科下一课”算出当天内容，记进 `days[日期].planned`。
- 晚上打卡时，只有打了“完成”的科目才前进一课。没学完的课，下一次排到这科时接着学**同一个讲义文件**。
- 英语从 2026-10-15 起是电影线：《当幸福来敲门》分 36 段，周一到周六每天一段（90 分钟），周日是本周复习（`review`，不推进）。电影没有讲义文件，用研习录里的跟读播放器（线网 → 英语·电影那条线，网址 `#c-film`）。
- 书架最下面一层是英语：一部电影或剧一个片盒（`src/data.js` 的 `english`）。《当幸福来敲门》的片盒按课表自动显示学到第几段；老友记、哈利·波特和绘本在 Baba 英语（https://baba.wogucloud.cn）上学，进度和生词暂时不传回研习录，用户在片盒面板里手动标状态。用户说在 Baba 上学了，打卡时照常记进足迹（`ref` 写片盒的 id，如 `en-friends`），不推进课表。
- CFA 的英文术语并进每节 CFA 课讲义的末尾（“英文术语”一节）。10 月 12—14 日的旧英语时段（`en`）只留在历史记录里。
- `progress.json` 的 `issued` 记着每科已经写好讲义的课数，研习录的课程页据此显示哪些课能打开。`today.js --record` 会自动更新它。

## 文件

- `study/lessons/<科目>/<两位序号>.md`：一课一个讲义，如 `study/lessons/sql/01.md` 是 SQL 第 1 课。第一次排到这一课的那天早上写，**以后不重写**（用户要求重写或补充时除外）。
- `study/daily/<日期>.md`：当天的路线单，很短：今天走哪几站（链到讲义文件）、昨天的情况、今晚打卡的问题。
- 有讲义文件的科目：`sql`、`py`、`cfa`、`geo`、`rev`（见 `src/plan.js` 的 `written`）。

## 命令

```bash
node study/today.js                  # 看今天（北京时间）的安排；每个时段的 file 是讲义文件，exists 表示已经写过
node study/today.js 2026-10-15       # 看某一天
node study/today.js --record         # 早上用：把今天的安排记进 progress.json，并更新 issued
node study/checkin.js 2026-10-15 --done film,sql,cfa --minutes 165 --note "……"
node study/checkin.js 2026-10-15 --done all
node study/checkin.js 2026-10-15 --done none
python3 build.py                     # 改完进度或讲义后重新生成 index.html
```

科目代号：`film` 英语·电影，`sql` SQL，`py` Python，`cfa` CFA 一级，`geo` 地缘政治，`rev` 周复盘，`prep` 准备日（`en` 是 10 月 12—14 日的旧英语时段）。

## 早上 7 点：写讲义和路线单

1. `git pull`，然后运行 `node study/today.js --record`，拿到当天的时段和课题。
2. 看前一天的记录：如果还是 `pushed`（没打卡），路线单开头提醒一句“昨天没打卡，按没学处理，今天接着学同一课；如果其实学完了，回复一句我来补记”。如果前一天的 `note` 里有没弄懂的问题，路线单开头先用一小段讲清楚。
3. 对每个带 `file` 的时段：`exists` 为 false 就按下面“讲义写法”写这个文件；为 true 就**不要重写**，路线单里直接链过去。
4. 写路线单 `study/daily/<日期>.md`（见“路线单写法”）。
5. `python3 build.py`，提交并推送（提交信息如“每日讲义 2026-10-15”）。然后按下面“同步到研习录云端版”更新进度、讲义和路线单。
6. 给用户发一条消息：今天几个时段、各学什么、合计多少分钟，附研习录链接 https://claude.ai/artifact/LpwLZchfacKZAnJs577MvM ，说明首页“今日路线”的每一站都能点开（电影那站打开跟读播放器，其余打开讲义）。用户如果在这次会话里提问，就地解答。

## 晚上 9 点：打卡

1. `git pull`，读当天的 `planned` 和路线单。
2. 给用户发消息，逐项列出今天的时段，请他回复：哪些学完了、大概用了多久、哪里没懂。电影那项问：第几段学完了没有、背熟了大概几句、有没有听不懂的句子（可以把那句贴过来）。给一个回复示例，如“电影第 3 段学完，SQL 完成，CFA 没做，用时 140 分钟，WHERE 和 HAVING 还是分不清”。
3. 收到回复后：运行 `checkin.js` 记录（电影学完了就在 `--done` 里写 `film`；周日的电影复习不推进，照常写进 `--done` 即可）；把没懂的地方当场讲清楚（用户贴来的台词可以逐句讲解，但不要自己补写电影的其他台词），并把问题写进 `--note`，第二天路线单开头再回顾一次；`python3 build.py`，提交并推送（“打卡 2026-10-15”）。
4. 按下面“同步到研习录云端版”更新进度，并在 `journal` 集合加一条学习足迹：id 为 `j-<日期去横线>-daily`，内容 `{ date, minutes, ref: "plan", text, t }`，`text` 写“每日课表：完成 电影第 3 段、SQL；……”加上用户说的收获或问题。没学的日子不记足迹。
5. 连续两天以上没打卡或没学，语气平和地问一句是不是时间排不开，需要的话把每天的量调小，而不是一直堆积。时间不够的日子可以只走电影一站（首页“保底”）。

## 同步到研习录云端版

研习录的主用版是 claude.ai 上的 Artifact（https://claude.ai/artifact/LpwLZchfacKZAnJs577MvM ），课表、讲义、课程页都从它的数据库读，不需要重新发布页面。每次 `progress.json` 或讲义变了之后：

1. 用 ArtifactData 工具（先用 ToolSearch 加载）`get` 集合 `study`、文档 `progress`，记下返回的 `version`；再 `set` 同一文档，`file_path` 指向 `study/progress.json`，`if_version` 填上一步的版本号。
2. 新写的每一课讲义，写进集合 `lessons`，文档 id 为 `<科目>-<两位序号>`（如 `sql-02`），内容 `{ key, md }`，`md` 是讲义文件全文。
3. 当天的路线单也写进集合 `lessons`，文档 id 为日期（如 `2026-10-15`），内容 `{ date, md }`。
4. 最省事的做法：`python3 study/lesson_json.py <键>` 生成 `/tmp/lesson-<键>.json`（键是日期或 `sql-02` 这样的课号），再 `set`，`file_path` 指向它。新建不用 `if_version`；重写已有文档时先 `get` 拿版本号。
5. 学习足迹写在集合 `journal` 里，新建文档不用 `if_version`。

工具不可用就跳过这一步，GitHub 上的公开版照样是最新的。只有改了页面代码（`src/` 下的文件）才需要用 Artifact 工具重新发布 `dist/artifact.html`。

## 讲义写法（一课一个文件）

讲义用中文写，术语保留英文。整课讲义要能直接照着学完，不需要另找材料。开头两行固定格式：

```
# SQL 第 2 课 · SELECT 与 FROM：取列、起别名、算新列

> 45 分钟 · SQL 第 2 / 36 课
```

正文用 `##` 分节，不写日期、不写“昨天”“今天”这类和某一天有关的话（这些写在路线单里），这样哪天学都能用。

- **SQL（45 分钟）**：本课目标；用他熟悉的筛查、比对场景讲概念；一段能直接粘贴到 DB Browser for SQLite 运行的建表加数据脚本；3–5 个示例查询，逐行解释；5 道练习，由易到难，最后一道贴近实际工作；常见错误；答案放在文末的 `<details>` 里。
- **Python（45 分钟）**：本课目标；讲解；能直接在 Jupyter 里运行的代码单元，需要的 Excel 用代码现场生成，不依赖外部文件；5 道练习，答案放在 `<details>` 里。
- **CFA（35 分钟）**：本课对应模块的学习目标；讲解；公式和计算例题（写出计算器步骤）；5 道仿一级考试格式的三选一选择题，答案和解析放在 `<details>` 里；最后一节“## 英文术语”：本课 8–10 个英文术语（英文、音标、中文，各配一句英文例句和译文）。
- **地缘政治**：周六那课说明读原书哪一章、哪几节，给出研习录精读页的入口（https://claude.ai/artifact/LpwLZchfacKZAnJs577MvM ），列 3 道思考题。周日那课先联网找一件最近一周的国际时事，给出用这一章框架分析的写作提示（写 300 字左右）。只用自己的话概括书的观点，不大段摘录原文。
- **周复盘（50 分钟）**：本周打卡统计；SQL、Python、CFA 小测各 5 题，再加本周 CFA 英文术语小测 10 题（答案折叠）；列出本周没完成的课；一个 20–30 分钟的小实战，用本周学的 SQL 或 Python 处理一份现场生成的模拟数据。
- **电影**：不写讲义，也不在任何文件里写电影的台词（版权）。跟读播放器读用户自己的字幕文件。

**模拟数据一律虚构**：姓名用明显虚构的名字，身份证号、账号等用虚构的格式，不要出现任何真实的人、单位或案件。
