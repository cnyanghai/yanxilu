## 一、装好 DB Browser for SQLite（约 15 分钟）

SQL 课前半程都用它。它是一个免费的图形界面小软件，数据库就是电脑上的一个 `.db` 文件，不需要装服务器、不需要联网。

**安装步骤**

1. 打开 sqlitebrowser.org → Download，Windows 选 *Standard installer for 64-bit Windows*（Mac 选 .dmg）。
2. 一路“下一步”安装。安装界面里如果有勾选项，勾上 *DB Browser (SQLite)* 的桌面快捷方式即可，SQLCipher 版本不用。
3. 打开软件 → 左上角 **New Database（新建数据库）** → 存到一个固定文件夹，例如 `D:\研习录\sql\practice.db`。
4. 弹出“编辑表定义”窗口时直接点 **Cancel（取消）**，我们用 SQL 语句建表。

**验收：跑通下面这段脚本**

切到 **Execute SQL（执行 SQL）** 标签页，把下面整段粘进去，按 `Ctrl + Enter`（或点三角形“执行全部”）：

```sql
-- 准备日验收脚本：建一张小表，插入 3 行虚构数据，再查出来
DROP TABLE IF EXISTS test_people;

CREATE TABLE test_people (
    id      INTEGER PRIMARY KEY,
    name    TEXT,
    city    TEXT,
    amount  REAL
);

INSERT INTO test_people (id, name, city, amount) VALUES
    (1, '甲某一', '虚构市', 1200.5),
    (2, '乙某二', '样例县', 800),
    (3, '丙某三', '虚构市', 1500);

SELECT name, city, amount
FROM test_people
WHERE city = '虚构市';
```

下方结果区应该出现 2 行：甲某一、丙某三。看到了就算装好了。最后点 **Write Changes（写入更改）** 保存。

**常见问题**

- 结果区什么都没有：确认是在 *Execute SQL* 页执行的，而不是 *Browse Data* 页。
- 报 `near "，": syntax error`：SQL 里的逗号、括号、引号必须是英文半角。中文输入法下打的 `，` `（` `‘` 都会报错——这是以后最常见的错误之一，今天先记住。
- 关软件时提示“是否保存”：选保存。

## 三、备好《大国政治的悲剧》（约 15 分钟）

地缘政治这门课第一阶段精读米尔斯海默的《大国政治的悲剧》（*The Tragedy of Great Power Politics*）。纸质、电子版都行，修订版（有讨论中国崛起的一章）更好。

**今天读什么**：只读**目录**和**第一章的开头几页**，不求读懂，先建立一个地图。

**读之前先知道这本书在吵什么**（下面是我的概括，不是原文）：

- 国际关系里有一派叫**现实主义**（realism），认为国家之间没有“世界政府”管着，所以每个国家最终只能靠自己保证安全。
- 现实主义内部又分两种看法：一种认为国家只要“够安全”就满足了（防御性现实主义）；作者主张另一种——**进攻性现实主义**（offensive realism）：在这种环境里，大国会不断寻找机会扩大自己相对于别国的实力，最理想的状态是成为所在地区的霸主。
- 书名里的“悲剧”指的是：没有哪个大国是天生的恶棍，但结构逼着它们互相防范、互相竞争，冲突因此反复出现。

## 六、热身小练习（可选，5 分钟）

不算正式内容，装好软件后有余力就做。

1. 在 DB Browser 里，把验收脚本最后的查询改成只查金额大于 1000 的人，应该出来几行？
2. 在 Jupyter 里，把单元格 3 的最后一行改成计算**所有人**的金额合计，结果是多少？
3. 假设年初存入 10,000 元，年末变成 10,800 元，这一年的收益率（return）是多少？

<details>
<summary>答案</summary>

1. 把 `WHERE city = '虚构市'` 改成 `WHERE amount > 1000`，出来 2 行：甲某一（1200.5）、丙某三（1500）。
2. `print(back["金额"].sum())`，结果 `3500.5`。
3. 收益率 = (期末 − 期初) ÷ 期初 = (10,800 − 10,000) ÷ 10,000 = 8%。这就是明天 CFA 第一课的起点——holding period return（持有期收益率）。
