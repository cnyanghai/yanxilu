# 研习录 · 气质定义与设计决定

改任何界面之前先读这一页。它记录的是用户定下来的东西，不是建议。

## 一句话

研习录是一间可以养的书房：你剪的、读的、写的，在里面长成东西；别人也能进来看。

## 用户的十条答案（2026-10-27）

1. 不只自己用，也给别人用。
2. 打开它的感觉像养花养鱼。
3. 电脑和手机都用。
4. 第一眼的感受：有逻辑的、立体的、整洁的、有内涵的。
5. 游戏感六分（0 是纯书房，10 是纯炉石）。
6. 喜欢的参考：igloo.inc，以及 Awwwards 的年度网站那一类。
7. 讨厌：像后台管理系统、像电商、像 PPT。
8. 主色调做几种，不必都一样。
9. 不要催。
10. 一年后长成什么样，每个人不一样。

## 由此定下的规矩

- **首屏主角是案头的文竹**（2026-10-28 定）：它是唯一随时间生长的物件，读得多它长叶，久不读它停长。今天的牌是桌上第二件东西。

- **核心动词是"养"**，不是"完成"。东西慢慢长、慢慢变；每天一点照料；没有红点、断签警告，只有落灰、草木停长这种物自己的变化。
- **一切有位置**：墙放书，架放盒，桌放牌；一个东西只在一个地方；全站没有列表页。
- **一种材质宇宙**：纸是主材（牌、袋、签、盒面），木只做舞台（桌、架、看板），墨是唯一的颜料（字、砚），铜是唯一的金属，只出现在能按的东西上（按钮有 3 像素厚度，按下去会沉）。不再有第五种材质。
- **一盏灯**：夜读房里桌灯是唯一光源，晴窗房里光从左窗来；所有阴影和高光都从它来。
- **一个镜头，三个景别**：远景整间房，中景一件家具，近景一件物。点一下是拉近，Esc 是拉远。手机是同一间房，镜头默认近一档。
- **三间房**：夜读（深木 + 灯）、晴窗（纸白 + 晨光）、雨天（青灰）。切换只换光，东西不换。
- **一屏一件事，说明文字归零**，控件藏在物件里；系统功能（搜索、账号）保持扁平小图标放在角落。
- **装饰必须承担信息**：牌背上每个元素都编码一个状态；不传达任何东西的动效一律去掉。
- **写是中心**：没有你自己的话的牌等于没打出去的牌；结卷是一篇你写的短文。
- **从第一天设计规模**：空的第一天、三十天、一年五百张牌时各是什么样；题目 40 字、1 字、全英文时怎么排。
- **游戏感六分**：留牌、包、结卷、宝石；不要金币、战斗、稀有度爆闪；开包是安静地揭开，纸响，不闪光。
- **可迁移**：数据能导出成纯文本；每个动作打点，一个月后用数据改。

## 牌的规矩

- 一篇文章一张牌。平时只看牌背：固定封面（圆光里月、远山、一盏灯、一卷书）+ 左上竖题签 + 右上铜钱（读完大约几分钟）+ 底边来源和宝石。一个领域一种底色，一盒就是一副牌。
- 宝石：灰没读 / 青读了 / 金写了批注 / 朱这一盒已结卷（盖"引"印）。待定：改成按"能不能回忆"定。
- 点牌翻过来放大，翻面就是整篇文章（阅读器）。
- 剪报夹是卡包：牛皮纸档案袋，缠绳扣、封条、朱印；有没拆的剪报就封着；拆过的袋子留着当夹子。

## 版本划分（2026-10-28）

- 现在的书架 + 档案架网页是**版本 1 系列**，git 标签 `v1`，保留并继续可开发。
- **版本 2 系列**是三维的小世界（院子 → 间 → 家具 → 物），立项分析、专家视角和分步路线在 `V2-ROADMAP.md`。本页的气质和规矩对两个版本都有效。
