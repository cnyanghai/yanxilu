## 建制

设计层照 Blizzard North（2000 年暗黑 2）的文化：先做出能玩的核心循环，再堆内容；一切是表；让人反复回来。美术与技术层照 Vicarious Visions（2021 年重制版）的现代建制：美术总监之下环境、道具、角色、动画、灯光、技术美术、界面各有专人。

## 流程

工作室的顺序，不是上来做光：

1. 愿景与支柱（游戏总监）
2. 设计文档：核心循环、系统、内容清单（设计岗）
3. 技术设计文档：架构、表、流水线、预算（技术岗）
4. 美术圣经（美术总监与美术部门）
5. 工具先行（工具程序）：编辑器与校验在内容之前
6. 第一个可玩版本：走路、开门、取书、读到正文
7. 垂直切片：一间房全部做到上线画质
8. 量产 → Alpha（系统全、占位美术）→ Beta（内容全）→ 上线 → 打磨

每一步推进前，相关岗位先开口，再动手。评审会由制作人与游戏总监主持，把各岗提案合成制作计划；决定记 STATUS 的"已定决策"，被否的记在提案文件末尾。

## 代理的用法（用户授权 Claude 自行判断）

- 大量阅读、要结论不要原文（源码、封包）→ 冷启动的只读代理并行。
- 需要知道项目全部决定的产出（部门提案、评审）→ 分叉代理，一岗一个，互相看不见。
- 执行类的活（烘焙、改代码、出图、提交）→ 不派，Claude 自己做。
