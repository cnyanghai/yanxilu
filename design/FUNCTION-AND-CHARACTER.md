# 研习录 · 版本 2 · 家具的功能、设计的高级感、小人（2026-10-30）

起因：用户看了 -Duduu- 的图文《岩洞村落》一些落地思路（抖音 7696959765440715775，AIGC × Photoshop × Tripo），提出三个要求：家具要有用、设计要更高级、三维小人要有特色。这页先拆那组图的方法，再回答三件事。

## 1. 《岩洞村落》的落地思路拆出来是什么

六张图是一条完整的"概念到可建造"的流水线，正是游戏美术的做法，只是每一步都换成了 AI：

1. **主视觉一张**：岩洞、圆窗、绿瓦、吊桥、瀑布，先把世界的气质定死。
2. **沙盘图加材质板**：整个村落切成一块"地层剖面"的沙盘（和我们"院子是被捧在手里的物件"同一个想法），四周用引线挂上材质样块（石、木、瓦、苔），旁边附俯视和剖面的线稿。材质在这一步就锁定了，后面所有东西都从这几块样块里取。
3. **主体建筑单独做**：从主视觉里抠出一栋房子 → Photobash 整理 → 干净的四视图（正侧背后） → Tripo 图生三维，得到 195 万面的高模。
4. **构件套件**：圆窗、门、托架、横梁做成一张"零件表"，Tripo 出四边面低模（2.6 万面），这些零件在所有房子上复用。**造型语言靠零件复用来统一**。
5. **室内一组、墙体模块、酒馆**：室内不是逐件出，是一组（沙发、圆形书柜、屏风、树枝灯、圆桌、地毯）作为一个"场景块"出图；岩壁上的圆窗做成可拼的墙体模块；酒馆配线稿。
6. **全套件平铺加地图**：屋顶件、岩洞件、瀑布件、梯田件、桥、植物、陶罐木桶、八个村民，全部平铺成一张套件表，最后一张手绘俯视地图决定怎么摆。

要点一句话：**先定气质和材质板，再把世界拆成可复用的套件，人物和道具也是套件的一部分，最后按地图摆。**

对我们直接有用的：
- 材质板挂引线的那张图，就是我们该有的"纸木墨铜"材质板：每种材质一块真实样块（宣纸、楠木、墨、黄铜），所有资产从这里取色取质感。
- 室内按"一组"出图而不是逐件：桌、椅、灯、花、砚一组出一张，风格天然统一，再拆件做三维。练习二的提示词要照这个改。
- 构件套件：我们的圆光、题签、朱印、绳扣、榫头，也该做成一张零件表，家具、卡片、界面上反复出现，这就是"高级感"的来源之一。
- 人物是套件：八个村民同一套衣服语言不同配色。我们的小人也要这么做。
- 工具：他用 Tripo（fal 上有），四边面低模选项正合我们要烘焙。

## 2. 家具有没有作用：每件东西至少承担一项功能或一个状态

BRIEF 说"装饰必须承担信息"，把它推进一步：**房间里没有纯装饰，每件家具要么是数据的容器，要么是一个动作的入口，要么显示一个状态。** 书房现有和拟加的每件对一遍：

| 家具 | 容器 / 动作 / 状态 | 具体 |
|---|---|---|
| 书墙 | 容器 | `books`，一本一物；抽出半截 = 在读；书口 = 进度；宝石 = 学到哪 |
| 档案架 | 容器 | `aboxes`、`clips`；盒 = 一个专题；袋 = 没拆的剪报；"引"印 = 结卷 |
| 案头的牌 | 动作 | 今天该读的那一篇；点开即读 |
| 文竹 | 状态 | 连续天数和读的量决定株数和层数；久不读停长，不枯 |
| 看板 | 状态 | 日期、没读、本周结卷、连着几天 |
| 灯 | 动作 + 状态 | 切夜读；亮着 = 今天读过 |
| 砚与笔 | 动作 + 状态 | 写批注、结卷的入口；砚里的墨随写的字数变深，一个月不写就干 |
| 读书椅 | 动作 | 坐下 = 开始一段计时的专注阅读；椅上搭的毯子颜色 = 这周读了几天 |
| 窗 | 状态 | 真实的时间和天气（晴窗 / 夜读 / 雨天默认跟真实走，也能手动切） |
| 地毯 | 状态 | 一年的学习年轮（版本 1 已有"学习年轮"）织进地毯的纹样 |
| 挂画 / 立轴 | 容器 | 摘抄册里最近一条划线，自动换 |
| 门 / 院门 | 动作 | 以后的社交入口：出门去别人的院子，别人来访在门口留牌 |
| 信箱 / 案上的信 | 容器 | 别人留下的话（以后） |
| 时钟 / 沙漏 | 状态 | 今天学了多久（版本 1 摆件库里已有会动的沙漏和钟） |
| 花房的植物 | 状态 | 每门课一盆，按课的进度长（花房的主题） |

规矩：加一件新家具前先填这张表，填不出来就不加。概念图 B 里的博古架、屏风、立轴都要先回答"它装什么、能点出什么、显示什么"。

## 3. 设计能不能更高级

"高级"不是更多装饰，是四件事，Duduu 那组图每一件都占：

1. **一种造型语言贯穿**：他的圆窗、绳扎、曲线屋脊出现在每栋房子上。我们的：圆光（牌背、窗、灯罩、挂画都是圆）、题签（书、盒、卡片、按钮）、朱印（结卷、封条、确认）、绳扣（袋、卷轴、灯线）、榫头（家具交接处露一点）。先做一张**零件表**，再做家具。
2. **材质板锁死**：纸木墨铜各一块真实样块，所有东西从样块取；不许出现第五种材质。
3. **细节有逻辑**：每个细节解释得出为什么在那里（结构、功能、使用痕迹），不是为了好看加的。砚边的墨渍、书口的指痕、灯罩内侧的熏黄，都是"用过"的痕迹。
4. **层次与留白**：前景一条切开的楼板边、中景家具、背景墙上一两件；大面积留空的纸白墙，东西少而大。

落到做法上：练习二和书房都先出"一组"的室内图（像 Duduu 第五张那样），再出零件表，再拆件。

## 4. 三维小人能不能有特色

kriss 的人是圆头黏土人，Duduu 的村民是写实布衣。我们的小人要从"纸木墨铜"里长出来，才有特色。三个方向，先出概念图再定：

- **A 纸人**：剪纸或折纸做的小人，纸白为底、墨线勾边、一点朱砂，关节是折痕，走路是一跳一跳的纸片感，风吹会晃。最贴材质纪律，最轻，最容易程序化动画。
- **B 墨童**：一团墨晕长出来的书童，边缘像宣纸上的渗墨，动起来有拖尾。识别度最高，但和"纸白干净"的房间对比强，要小心用量。
- **C 木偶**：榫卯木偶，关节是圆木销，铜钉做眼睛，像案头的文玩。最有"物"感，但动画最费。

小人做什么（功能先于造型）：
- **书童**一个：每天把今天的牌放到案头；你读的时候坐在读书椅旁翻书；你结卷时盖印；久不来，它在门口张望。它是"养"的具象，不是装饰。
- **访客**：以后别人进你的院子，是他们自己的小人（同一套纸人语言、不同配色和题签），在院子里走到哪间就看哪间。
- 小人**不说话、不弹窗、不催**，只有动作。

做法：按 Duduu 的"人物套件"思路，一个基础小人加可换的配色、题签、手持物（书、灯、印），全部同一套骨架和动画。动画用程序化关键帧（走、坐、翻、盖印、张望五个动作），不做骨骼蒙皮。
