# 研习录奇幻界面 · 场景与进场动效（设计稿）

2026-11-06，用户口述的设想，同日晚用三张图补了"印象中的样子"。蓝图见 docs/ui-system-plan.md，画风见 docs/ui-style-bible.md（第三稿：紫夜墓场）；本稿只定"三个区各是什么场、进场怎么演、怎么做出来"。灰盒原型在 docs/ui-motion-proto.html（只有形状与时间，没有美术），分镜图 docs/ui-motion-storyboard.png。

## 一、用户的设想（归纳，含三张图之后的修正）

- 打开 App 是一张独立的首页：紫夜的墓场，枯枝从顶上压下来，前景的墓碑睁着绿眼，远处山上一座亮着窗的宅子（图一）。首页上放选项。2026-11-06 晚看图四改：首页是墓园大门——前景一道门框住画面、门内一条路和路牌、远景林与宅；三碑并排的首页碑太大太多、层次不够，作废。
- 书架：从墓地里钻出一座黑哥特尖拱书架（图二）：窗花格、两侧烛台、挂饰骷髅、乌鸦；书像幽灵一样汇聚凝成。点开一本书有自己的打开动效。
- 档案柜：一片刻字的碑林（图三），**一座碑就是一只档案夹，碑上刻的字就是夹名**；点一座碑，一排排卡片飞出来，**呈圆弧状摆开**。
- 笔记本：**一只只骷髅手臂从地下伸出来，各抓着一本笔记本**（不是整只骷髅）。
- 已定：主题只做墓地一套、三区共用；全长 3.5 秒、短版 0.8 秒。

## 二、这改了什么

1. 首页正常页改成独立的墓场进场页；三个区各一个场，共用一片天与地，但功能场用没有前景碑的「空场」背景，首页的门与路牌不跟进去。书架要占满屏（高 ≥ 85%），碑要大到字读得清（圣经第八之三节）。
2. 进场戏是每个区的仪式，必须有"第一次全长、之后短版、点一下跳过"。
3. 书、卡、本子仍由数据长出来：汇聚的幽灵数是书数，碑数是夹数，碑上刻的是夹名，手臂数是本子数。场是画的，内容是算的。
4. 笔记本从整只骷髅改成手臂：不用绑骨，三个姿势（伸出、举着、递上）用生图抠底加 transform 就能做。整套里不再有需要角色动画的东西。

## 三、三段进场的分镜（全长版，约 3.5 秒）

### 首页：门开，路牌亮

| 时刻 | 画面 | 声 |
|---|---|---|
| 0 到 0.5 秒 | 雾里只有门的黑剪影，门关着，远处宅子的窗先亮 | 风 |
| 0.5 到 1.2 秒 | 拱上的牌从牌后透出琥珀光，「研习录」三个字亮起来 | 烛"噗"一声 |
| 1.2 到 2.4 秒 | 两扇门吱呀向内打开，路从雾里显出来，路边的木路牌和三块牌跟着显出 | 铁门吱呀，合页一声 |
| 2.4 到 3.5 秒 | 门柱上的灯笼亮（继续上次），乌鸦落到拱顶，雾开始流 | 无 |

点一块路牌：镜头顺着路推过门，雾盖住画面，淡入那个区的进场戏；短版 0.8 秒只有门开，接着切场。

### 书架：哥特书架钻出，幽灵凝成书

| 时刻 | 画面 | 声 |
|---|---|---|
| 0 到 0.3 秒 | 地面先抖，土扬起，雾被顶开一个洞 | 低沉的地鸣 |
| 0.3 到 1.6 秒 | 黑哥特宽柜（单拱 2:1，占满屏宽）整座从土里钻出来，升的时候左右颤抖、幅度渐小，土从檐和格层上掉；烛台最后亮 | 木与石摩擦，落定一声闷响，烛"噗"一声 |
| 1.6 到 3.2 秒 | 绿色幽灵从雾里和画面边缘冒出，摇摆着飞向各自的格位，到位时亮一下、凝成书脊；每本书对应一个幽灵，按格错开 | 风声，每本凝成一声小的叮 |
| 3.2 到 3.5 秒 | 书架轻轻一沉再回，乌鸦落到顶上，进入可用状态 | 无 |

点开一本书：书从格里向前抽出、放大到台面，封面翻开成两页，背景压暗，烛光跟到书上。

### 档案柜：碑林长出，点碑卡片圆弧摆开

| 时刻 | 画面 |
|---|---|
| 0 到 0.3 秒 | 地面抖、土扬 |
| 0.3 到 1.8 秒 | 碑一座座错开从地里长出（先慢后快再停住），碑面上的夹名一个字一个字刻出来；碑高矮不一、前后两排、各歪几度（圣经第八之二节的错落规则），多于一屏横向排成碑林，雾在碑脚 |
| 1.8 到 3.2 秒 | 卡从上方与两侧旋着飞进各自的碑里，碑上的篇数跳动 |
| 3.2 到 3.5 秒 | 落定，碑眼眨一下 |

点一座碑（终态后）：卡从碑顶飞出，沿一道圆弧摆开成一把扇，每张略转向圆心，约 0.5 秒；点一张卡放大看详情，点空处收回碑里。卡多于十二张时扇只摆最近十二张，其余叠在扇尾，再点一次翻下一把。

### 笔记本：骷髅手臂伸出，抓着本子

| 时刻 | 画面 |
|---|---|
| 0 到 0.4 秒 | 空地，土先鼓起来 |
| 0.4 到 2.4 秒 | 骨臂一只只错开从土里伸出、举稳，各抓一本封面朝观者的本子；长短角度不一、前后两排、各歪几度；随手本的那只最先、最靠前、最大 |
| 2.4 到 3.5 秒 | 闲时动作：手臂轻微晃、本子微微转 |

点一本：那只手臂把本子举到前面，本子翻开成对开（现有随手本的两页）。「＋ 新本子」是一只空着的手伸出来等你放一本。

## 三之二、三件交互的分镜（阶段 1 样稿）

### 书从架上点开

| 时刻 | 画面 | 声 |
|---|---|---|
| 0 到 0.18 秒 | 点中的书脊向前抽出半截，相邻两本微微让开 | 木与皮一声轻擦 |
| 0.18 到 0.5 秒 | 书飞到画面中央放大成封面正视图，背景压暗、烛光跟到书上 | 风 |
| 0.5 到 0.9 秒 | 封面翻开成对开：左页目录（章节、读到哪）、右页正文首页或书皮近看；书签垂在中缝 | 纸翻过的一声 |

退出反向"放回去"：合上、缩回、插回格里。短版 0.3 秒直接切到对开。

**手机上的实际阅读（用户 2026-11-06 深夜：要考虑手机上的实际阅读使用）**，四屏：

1. **架上**：手机版书架一屏一到两层格（宽柜按格层切开竖排），书脊宽 ≥ 16 像素、题签竖排。点一本：书脊向前弹出半截 0.18 秒，同层其余书暗下去。
2. **封面**：书飞到屏中央放大成封面（宽占屏 70%，2:3），墓园背景压暗到三成，烛光跟到书上；封面下一条石尺写读到百分之几、上次读是几天前；两个动作：「接着读」（主）与「目录」。点封面也等于接着读。
3. **阅读页**：单页，不是对开。骨白纸铺满屏（纸纹极淡，不抢字），上下各一条细石尺：顶尺左书名右章名，底尺左「合上」、中间第几页、右进度线。正文默认 18 像素可调 16 到 22，行高 1.75，每行 18 到 22 字，左右边距 20 像素；墨黑字 #1C1A17 在骨白 #EFE8D6 上对比约 12:1；夜读：纸 #16141A、字 #CFC8B6，对比 ≥ 9:1。翻页：左右轻扫或点两侧四分之一，翻纸影 0.24 秒；点中间收起或显示两条石尺；长按选字划线四色、批注照旧。
4. **目录**：从右侧滑进一条书签抽屉（占屏宽 80%），章节、读到哪的标记、每章划线数；点章跳转。

退出：底尺「合上」，书合上缩回架上，反向 0.3 秒。阅读页不画场景，墓园只在架上与封面两屏出现；阅读页的装饰只有两条石尺和纸纹，首屏图量 ≤ 300 KB。桌面宽 ≥ 1100 像素才用对开（左目录右正文，放在石祭坛台面上），否则也用单页。灰盒原型 `ui-book-proto.html`（手机尺寸），分镜图 `ui-book-storyboard.png`。

### 墓碑卡片

点碑：卡从碑顶一张张飞出，沿圆弧摆成一把扇（第四节已有），0.6 秒；点一张卡：其余卡退到雾里，这张放大到画面中央 0.3 秒，再点翻到背面 0.42 秒。退出：卡飞回碑顶、碑面合上。

**手机上的实际使用（2026-11-06 深夜，书过门后接着定）**，四屏：

1. **碑列**：一屏一座碑，宽占屏 70% 以上，左右滑换夹；碑面刻夹名与篇数。点碑。
2. **扇开**：碑缩到顶部成碑额（夹名、篇数），卡从碑顶飞出沿圆弧在屏下半摆成一把扇，张张重叠、露出各自的题签，弧顶在中间；左右拖扇转动，0.6 秒。卡多于九张时扇只露九张，拖着转。
3. **牌放大**：点一张，其余退到雾里，这张升到屏中央放大到宽 80%。牌面：题签（标题）、来源、一句为什么存、右上铜钱写读完约几分钟、底边一颗宝石写状态——状态靠形状也靠明暗：空圈没读、实心读了、羽毛写了批注、「引」印这盒结卷。两个动作「翻过来读」「放回」，0.3 秒。
4. **牌背就是文章**：翻面 0.42 秒，背面用书的单页阅读模板（两条石尺、纸纹、18 像素正文），顶尺写夹名·标题，底尺「放回」；划线批注照旧。

退出：放回 → 牌飞回碑顶 → 碑面合上。桌面：碑林加圆弧扇（灰盒第四节），牌放大在中央、正反面并排可切。牌的材质定为**羊皮纸牌**：骨白旧纸、墨线双框、四角铁包角、上三分之一一块题签板、底边蜡封位；牌背深青底、圆光里一幅墓园大门小景加题签。灰盒 `ui-card-proto.html`，分镜 `ui-card-storyboard.png`，线框 `ui-card-wireframe.jpg`。

### 笔记本打开

骨臂把本子举到前面（第五节已有），0.42 秒后翻开成对开：左页是上一页，右页是今天；纸面骨白带纸纹，手写字 Ma Shan Zheng，页角日期印；记一笔是在右页底部写一行，落笔有墨点。退出：合上、递回。

**手机上的实际使用（2026-11-06 深夜，卡片过门后接着定）**，四屏：

1. **笔记场**：一屏一只骨臂举一本，本子宽占屏六成以上，左右滑换本；封面题签写本名，随手本在最前。点本子。
2. **递本**：骨臂把本子举到屏中央 0.42 秒，封面放大到宽七成；封面下一条石尺写「今天 11 月 6 日 · 已记 3 笔」；两个动作「翻开今天」「日历」。
3. **今天这一页**：单页，骨白纸纹（与书共用 P024，去暗角）；页角一枚日期印（锈橙朱文方印，印里是日期，代码画）；正文手写字 Ma Shan Zheng 20 像素、行高 1.8，每笔一段、段尾一行小字写几点记的；底部一条「记一笔」写入条（铅笔图标），写完回车落笔有墨点 0.18 秒；左右滑翻到前一天 / 后一天，翻纸影 0.24 秒；点中间收起石尺。
4. **日历抽屉**：从右滑进，按月列出有字的日子和各记了几笔，点一天跳过去；顶部一条搜索框（搜笔记）。

退出：合上 → 递回骨臂。桌面对开放在石台面上（与书共用 P023）：左页昨天、右页今天。灰盒 `ui-notes-proto.html`（手写字直接用 vendor/fonts 里的 Ma Shan Zheng），分镜 `ui-notes-storyboard.png`，线框 `ui-notes-wireframe.jpg`。零件只差本子封面一表（六本，封面题签留白），纸面与对开共用书的。

## 四、规矩

- **长短版**：当天第一次进全长；之后 0.8 秒短版（家具已在位，只有幽灵快速归位、卡快速入碑、手臂快速举稳）；点一下或开始滚动就跳过到终态。
- **减少动态**：系统开了减少动态就直接终态，不演。
- **帧率预算**：手机上粒子不超过 30 个同屏（桌面 60），拖尾用 canvas 叠一层，不用 DOM 做粒子；家具的钻出与手臂的伸出用 transform。
- **先灰盒后美术**：节奏过了再换成画。
- **一次加一层**：静态终态 → 家具钻出 → 粒子 → 光与土 → 声音，每层真机看一遍。

## 五、每样东西怎么做

| 东西 | 做法 | 已有 |
|---|---|---|
| 背景两张 | 首页用「墓园大门」（P011，图四的构图）；三个功能场用「空场」（同一片天、枯枝、宅子、路、雾，前景无碑，用 edit 端点拿首页图当参考出，保证是同一片地），各加两层视差（雾、近景枝），手机竖版另出 | 首页图已有（P004） |
| 哥特书架 | 英雄家具：生图抠底（第二轮试笔乙）或 Blender 三维按专业流程出透明底图；钻出的颤抖是 transform 曲线，掉土是 canvas 粒子 | 书柜模块、tools/ui/cut.py |
| 档案碑 | 生图透明底出三种碑形的零件表，`cut.py --split` 拆开，碑面留空板，夹名用带内阴影的文字刻上去；排布按错落规则 | cut.py |
| 幽灵与卡的汇聚、卡片圆弧摆开 | canvas 粒子与 DOM 变换：幽灵从边缘出发正弦摇摆飞向格位，到位换成真书脊；卡的扇形是 DOM 卡片按圆弧角度 transform | 书脊与卡已由数据生成 |
| 骷髅手臂 | 生图透明底出三种骨臂的零件表，拆成臂与本子两层（本子封面由数据换），三个姿势各一张；伸出 = 从地平线以下 translate 上来加掉土；排布按错落规则 | cut.py --split |
| 打开书 / 碑面翻开 / 递本子 | CSS 三维变换的翻页加压暗背景 | 展台、档案夹对开、笔记本对开的位置都在 |
| 声音 | 一动一声，CC0 音源，默认静音可开 | 无 |
