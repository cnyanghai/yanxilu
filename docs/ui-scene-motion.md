# 研习录奇幻界面 · 场景与进场动效（设计稿）

2026-11-06，用户口述的设想。总计划见 docs/ui-system-plan.md，画风仍是绘本厚涂；本稿只定"三个区各是什么场、进场怎么演、怎么做出来"。灰盒原型在 docs/ui-motion-proto.html（只有形状与时间，没有美术）。

## 一、用户的设想（归纳）

- 打开 App 是正常的首页。
- 点「书架」进书架页：背景可以是靛蓝、深空或海滩；一个书架坠落或升起。以墓地为例：一座死灵墓碑书架颤抖着从地里升起，书像幽灵一样从四面汇聚、凝成一本本书。点开一本书也有自己的打开动效。
- 「档案柜」同理：墓地背景，一座座墓碑从地里长出来，就是一个个档案柜；一篇篇文章汇聚成卡牌飞进墓碑。
- 「笔记」：空地里一个个骷髅爬出来，每个手上捧着一本笔记。

## 二、这改了什么

1. 原计划是"一间书房、七种屏幕"；现在是**首页正常，三个区各有一个场**，场有主题（靛蓝 / 深空 / 海滩 / 墓地……）。主题是一套可换的「主题包」：背景、家具的形制（书架长成墓碑）、进场戏、汇聚粒子的样子、声音。
2. 进场戏成了英雄时刻。它不是装饰，是每次进这个区的仪式，所以要有"第一次全长、之后短版、点一下跳过"的规矩，否则第三天就烦。
3. 书、卡、本子仍由数据长出来：汇聚的幽灵数就是真实的书数，墓碑数就是档案夹数，骷髅数就是本子数。场是画的，内容是算的，这条不变。
4. 骷髅是角色。角色要动（爬出、捧、闲时呼吸），这是整套里唯一需要角色动画的地方，也是最贵的一项。

## 三、三段进场的分镜（全长版，约 3.5 秒）

### 书架：墓碑书架升起，幽灵凝成书

| 时刻 | 画面 | 声 |
|---|---|---|
| 0 到 0.3 秒 | 地面先抖，几团土扬起，镜头微颤 | 低沉的地鸣 |
| 0.3 到 1.6 秒 | 墓碑形的书架从地里升起，升的时候左右颤抖、幅度渐小，土从边上掉 | 石头摩擦，落定时一声闷响 |
| 1.6 到 3.2 秒 | 幽灵（光点拖尾）从画面边缘与地面冒出，摇摆着飞向各自的格位，到位时亮一下、凝成书脊；每本书对应一个幽灵，按格错开出发 | 轻的风声，每本凝成时一声小的叮 |
| 3.2 到 3.5 秒 | 书架轻轻一沉再回，光尘散去，进入可用状态 | 无 |

点开一本书：书从格里向前抽出、放大到台面，封面翻开成两页（现有展台的位置），背景压暗。

### 档案柜：墓碑长出，文章化卡飞入

| 时刻 | 画面 |
|---|---|
| 0 到 0.3 秒 | 地面抖、土扬 |
| 0.3 到 1.8 秒 | 墓碑一座座错开长出（先慢后快再停住），每座一个档案夹；多于一屏时横向排成一列墓地 |
| 1.8 到 3.2 秒 | 卡从上方与两侧旋着飞进各自的墓碑，碑上计数跳动 |
| 3.2 到 3.5 秒 | 落定 |

点一座墓碑：碑面翻开成档案夹对开（docs/archive-design.md 第六节的形式）。

### 笔记本：骷髅爬出，手捧本子

| 时刻 | 画面 |
|---|---|
| 0 到 0.4 秒 | 空地，一只手先从土里伸出 |
| 0.4 到 2.4 秒 | 骷髅一个个错开爬出、站定，各捧一本；随手本的那个最先、站最前 |
| 2.4 到 3.5 秒 | 闲时动作：轻微起伏、偶尔歪头，本子封面朝观者 |

点一本：骷髅把本子递到前面，本子翻开成对开（现有笔记本的两页）。

## 四、规矩

- **长短版**：当天第一次进全长；之后 0.8 秒短版（家具已在位，只有幽灵快速归位）；任何时候点一下或开始滚动就跳过到终态。
- **减少动态**：系统开了减少动态就直接终态，不演。
- **帧率预算**：手机上粒子不超过 60 个同屏，拖尾用 canvas 叠一层，不用 DOM 做粒子；家具的升起用 transform 不用改布局。
- **先灰盒后美术**：原型先用形状验时间与节奏，节奏过了再换成画。节奏不过，美术再好也白搭。
- **一次加一层**：静态终态 → 家具升起 → 粒子 → 光与尘 → 声音，每层真机看一遍。

## 五、每样东西怎么做

| 东西 | 做法 | 已有 |
|---|---|---|
| 背景（靛蓝 / 深空 / 海滩 / 墓地） | 生图一张加两层视差（远景、雾），手机竖版另出一张 | 书柜场景已有桌面与手机两版的做法 |
| 墓碑书架、墓碑档案柜 | 英雄家具：Blender 三维按专业流程出透明底图，或生图加抠底；升起的颤抖是 transform 曲线，掉土是 canvas 粒子 | 书柜模块、tools/ui/cut.py |
| 幽灵与卡的汇聚 | canvas 粒子：从边缘出发，正弦摇摆加缓动飞向格位，到位换成真实的书脊 / 卡 DOM | 书脊与卡已由数据生成 |
| 骷髅 | 三条路：甲 Blender 骨骼动画渲成序列帧（专业流程，可换动作）；乙 生图拆四肢后在 Rive 里做骨骼与状态机（要自带运行时）；丙 生图序列帧（不可控，不推荐）。建议甲 | tools/blender/ |
| 打开书 / 翻开碑 / 递本子 | CSS 三维变换的翻页加压暗背景 | 展台、档案夹对开、笔记本对开的位置都在 |
| 声音 | 一动一声，CC0 音源，默认静音可开 | 无 |

## 六、成本与风险

- 时间：灰盒原型半天；一个主题包的美术（背景三张、两件家具、粒子样式）约两到三天；骷髅走 Blender 序列帧另加两到三天。
- 钱：生图在总计划的 90 元内；骷髅若请人另算。
- 风险：进场戏每天看会烦（靠长短版与跳过）；手机帧率（靠粒子上限）；墓地主题与读书这件事的气质是否相称，由你定；多主题意味着美术成倍，建议先只做一套。

## 七、请你定的事

1. 主题先做一套还是做成可选？建议先只做墓地一套，做到位再谈第二套。
2. 三个区共用一个主题，还是书架深空、档案墓地、笔记空地各自一个？
3. "正常的首页"是现在这个首页吗？
4. 全长 3.5 秒、短版 0.8 秒、点一下跳过，这三个数可以吗？
5. 骷髅这种角色要不要？要的话走 Blender 序列帧。
6. 要不要声音（默认静音可开）。
