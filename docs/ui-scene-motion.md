# 研习录奇幻界面 · 场景与进场动效（设计稿）

2026-11-06，用户口述的设想，同日晚用三张图补了"印象中的样子"。蓝图见 docs/ui-system-plan.md，画风见 docs/ui-style-bible.md（第三稿：紫夜墓场）；本稿只定"三个区各是什么场、进场怎么演、怎么做出来"。灰盒原型在 docs/ui-motion-proto.html（只有形状与时间，没有美术），分镜图 docs/ui-motion-storyboard.png。

## 一、用户的设想（归纳，含三张图之后的修正）

- 打开 App 是一张独立的首页：紫夜的墓场，枯枝从顶上压下来，前景的墓碑睁着绿眼，远处山上一座亮着窗的宅子（图一）。首页上放选项。
- 书架：从墓地里钻出一座黑哥特尖拱书架（图二）：窗花格、两侧烛台、挂饰骷髅、乌鸦；书像幽灵一样汇聚凝成。点开一本书有自己的打开动效。
- 档案柜：一片刻字的碑林（图三），**一座碑就是一只档案夹，碑上刻的字就是夹名**；点一座碑，一排排卡片飞出来，**呈圆弧状摆开**。
- 笔记本：**一只只骷髅手臂从地下伸出来，各抓着一本笔记本**（不是整只骷髅）。
- 已定：主题只做墓地一套、三区共用；全长 3.5 秒、短版 0.8 秒。

## 二、这改了什么

1. 首页正常页改成独立的墓场进场页；三个区各一个场，共用一片天与地。
2. 进场戏是每个区的仪式，必须有"第一次全长、之后短版、点一下跳过"。
3. 书、卡、本子仍由数据长出来：汇聚的幽灵数是书数，碑数是夹数，碑上刻的是夹名，手臂数是本子数。场是画的，内容是算的。
4. 笔记本从整只骷髅改成手臂：不用绑骨，三个姿势（伸出、举着、递上）用生图抠底加 transform 就能做。整套里不再有需要角色动画的东西。

## 三、三段进场的分镜（全长版，约 3.5 秒）

### 书架：哥特书架钻出，幽灵凝成书

| 时刻 | 画面 | 声 |
|---|---|---|
| 0 到 0.3 秒 | 地面先抖，土扬起，雾被顶开一个洞 | 低沉的地鸣 |
| 0.3 到 1.6 秒 | 黑哥特尖拱书架从土里钻出来，升的时候左右颤抖、幅度渐小，土从檐和格层上掉；两侧烛台最后亮 | 木与石摩擦，落定一声闷响，烛"噗"一声 |
| 1.6 到 3.2 秒 | 绿色幽灵从雾里和画面边缘冒出，摇摆着飞向各自的格位，到位时亮一下、凝成书脊；每本书对应一个幽灵，按格错开 | 风声，每本凝成一声小的叮 |
| 3.2 到 3.5 秒 | 书架轻轻一沉再回，乌鸦落到顶上，进入可用状态 | 无 |

点开一本书：书从格里向前抽出、放大到台面，封面翻开成两页，背景压暗，烛光跟到书上。

### 档案柜：碑林长出，点碑卡片圆弧摆开

| 时刻 | 画面 |
|---|---|
| 0 到 0.3 秒 | 地面抖、土扬 |
| 0.3 到 1.8 秒 | 碑一座座错开从地里长出（先慢后快再停住），碑面上的夹名一个字一个字刻出来；碑高矮不一、前后两排、各歪几度（圣经第八之二节的错落规则），多于一屏横向排成碑林，雾在碑脚 |
| 1.8 到 3.2 秒 | 卡从上方与两侧旋着飞进各自的碑里，碑上的篇数跳动 |
| 3.2 到 3.5 秒 | 落定，碑眼眨一下 |

点一座碑（终态后）：卡从碑顶飞出，沿一道圆弧摆开成一把扇，每张略转向圆心，约 0.5 秒；点一张卡放大看详情，点空处收回碑里。卡多于十二张时扇只摆最近十二张，其余叠在扇尾，再点一次翻下一把。

### 笔记本：骷髅手臂伸出，抓着本子

| 时刻 | 画面 |
|---|---|
| 0 到 0.4 秒 | 空地，土先鼓起来 |
| 0.4 到 2.4 秒 | 骨臂一只只错开从土里伸出、举稳，各抓一本封面朝观者的本子；长短角度不一、前后两排、各歪几度；随手本的那只最先、最靠前、最大 |
| 2.4 到 3.5 秒 | 闲时动作：手臂轻微晃、本子微微转 |

点一本：那只手臂把本子举到前面，本子翻开成对开（现有随手本的两页）。「＋ 新本子」是一只空着的手伸出来等你放一本。

## 四、规矩

- **长短版**：当天第一次进全长；之后 0.8 秒短版（家具已在位，只有幽灵快速归位、卡快速入碑、手臂快速举稳）；点一下或开始滚动就跳过到终态。
- **减少动态**：系统开了减少动态就直接终态，不演。
- **帧率预算**：手机上粒子不超过 30 个同屏（桌面 60），拖尾用 canvas 叠一层，不用 DOM 做粒子；家具的钻出与手臂的伸出用 transform。
- **先灰盒后美术**：节奏过了再换成画。
- **一次加一层**：静态终态 → 家具钻出 → 粒子 → 光与土 → 声音，每层真机看一遍。

## 五、每样东西怎么做

| 东西 | 做法 | 已有 |
|---|---|---|
| 首页与三场的背景 | 生图一张（紫夜、枯枝压顶、宅子）加两层视差（雾、近景枝），手机竖版另出一张 | 书柜场景已有桌面与手机两版的做法 |
| 哥特书架 | 英雄家具：生图抠底（第二轮试笔乙）或 Blender 三维按专业流程出透明底图；钻出的颤抖是 transform 曲线，掉土是 canvas 粒子 | 书柜模块、tools/ui/cut.py |
| 档案碑 | 生图透明底出三种碑形的零件表，`cut.py --split` 拆开，碑面留空板，夹名用带内阴影的文字刻上去；排布按错落规则 | cut.py |
| 幽灵与卡的汇聚、卡片圆弧摆开 | canvas 粒子与 DOM 变换：幽灵从边缘出发正弦摇摆飞向格位，到位换成真书脊；卡的扇形是 DOM 卡片按圆弧角度 transform | 书脊与卡已由数据生成 |
| 骷髅手臂 | 生图透明底出三种骨臂的零件表，拆成臂与本子两层（本子封面由数据换），三个姿势各一张；伸出 = 从地平线以下 translate 上来加掉土；排布按错落规则 | cut.py --split |
| 打开书 / 碑面翻开 / 递本子 | CSS 三维变换的翻页加压暗背景 | 展台、档案夹对开、笔记本对开的位置都在 |
| 声音 | 一动一声，CC0 音源，默认静音可开 | 无 |

## 六、成本与风险

- 时间：灰盒原型已有；一个主题的美术（背景三张、书架、碑、手臂、粒子样式）约两到三天。
- 钱：第二轮试笔约 3 元；全套在蓝图的约 55 元内。
- 风险：进场戏每天看会烦（靠长短版与跳过）；手机帧率（靠粒子上限）；紫与绿是用户选的气氛，色弱规则把意义从颜色上拿掉；卡片扇形在手机上摆不开（手机改成竖向一列从碑里升出）。
