# 研习录奇幻界面体系 · 蓝图与生产计划

2026-11-06 立，同日晚按用户口述的设想改写为蓝图，再按用户发来的三张图（紫夜毒绿墓场、黑哥特尖拱书架、刻字碑林）修正。用户定：**画风厚涂加墨线、紫夜哥特气质；主题先只做墓地一套，三个区共用；首页是一进 App 的独立一页，一片墓场，上面放选项；进场戏全长 3.5 秒、短版 0.8 秒；档案碑上刻夹名、点碑卡片圆弧摆开；笔记本是从地里伸出的骷髅手臂抓着本子**。目标仍是一个完整、成体系、像游戏的网站和 App（同一套网页，App 即 PWA）。风格细则在 `ui-style-bible.md`，进场戏分镜与灰盒原型在 `ui-scene-motion.md` 与 `ui-motion-proto.html`，样图怎么做的在 `ui-craft-and-pipeline.md`。各件物件的详稿另开（档案见 `archive-design.md`，书柜三维流程见 `bookcase-production.md`）。

## 二、它是一个什么样的"游戏"：一片月夜墓场

### 首页：墓园大门（进场页）

一进 App 先到这里，像游戏的标题画面。2026-11-06 晚按用户的图四改：一道黑铁墓园大门在前景框住画面，两根石柱、顶上的铁花拱托一块牌刻「研习录」、烛光从牌后透出，门扇向内半开、枯藤缠柱、柱顶小石像鬼；门内一条石板路进墓园，路边一根木路牌三块牌写 **书架 / 档案架 / 笔记本**，指到时牌亮；远景雾里的枯林和山上亮窗的宅子（与空场同一座，进门就是三个场所在的墓园）。门柱上挂的灯笼是「继续上次」（回到上回停的那本或那页）。点一块路牌，镜头顺着路推过门，接那个区的进场戏。三碑并排的首页作废：碑太大太多、层次不够（P004 留作对照）。
贴边不进画的四件 HUD：灯笼（布置与设置）、放大镜（搜索）、羽毛笔（记一笔，快捷键 N 照旧）、印（打卡）。公开版与服务器版同一张首页，服务器专有的剪报入口是碑旁一只信箱。

## 四、生产线

四条路，各管一类东西，最后都进同一道调色与同一面对照墙：

```
背景与零件：样式图（概念表） → 报提示词与张数 → gpt-image-2（fal_image2.py，中档，零件加 --bg transparent 直接出透明底）
            → cut.py 只拆零件表与修边 → 切 nine.py / tile.py → 统一调色 → WebP 两档 → vendor/ui/ 登记 kit.json
            → 给人看的一律先贴到场景底上（不看洋红或透明底原图）
英雄家具：  量尺（蓝本是乙试笔图） → Blender 粗模 → 高模 → 分层材质 → 看光（月光加灯笼） → 渲透明底
            → 必要时叠一道厚涂处理（笔触与纸纹）让它和生图的零件像一家 → WebP
骷髅手臂：  丁试笔图 → 抠底拆成臂与本子两层 → 三个姿势各一张 → transform 做伸出、举稳、递上（不绑骨不渲帧）
由数据长出的：书脊与封面（从生图零件表里按编号挑一根，题签与状态叠上去）、卡的字、本子纸面、计数、状态印 → 代码，叠在上面三层之上
```

一致性四条：提示词固定前导段；同类物件同一张表出；全部出图过同一道调色；三维渲染的光与生图的光方向一致（月光从上、灯笼在近处）。每件东西的小循环：样式图 → 生成或建模 → 抠底切片 → 进页 → 并排参考过门，门不过不往下走。

## 六、预算与节奏

生图改为 gpt-image-2 高档 1.5 元一张带图四当锚（nano 不够厚，中档不够细）：英雄图与零件表约 40 张、重滚约 15 张，**全套约 90 元**，已花约 30 元。阶段 0 两轮约 5.3 元，阶段 0 到 2 约 20 元就能看到首页与书架场的完整样子，到时再决定铺不铺开。笔记本改成手臂后不再有需要绑骨的东西，三维只在要改角度尺寸时才上。

## 七、风险

- **恐怖感**：日用的学习工具，墓地主题一不小心就阴森。圣经定了"温和不恐怖"，试笔丙专门验骷髅的脸。
- **进场戏疲劳**：长短版、点一下跳过、减少动态时不演，三条写进代码不写进"以后"。
- **首页多一跳**：原来打开就是书墙，现在多一页。灯笼「继续上次」一键回到上回的地方，手机上首页可下滑直接进上次的场。
- **紫与绿**：用户选的气氛是紫夜加毒绿光，红绿色弱看绿光与琥珀烛光会接近，所以意义一律不放在颜色上（圣经第二节），只放在形状、明暗、文字与印。
- **一致性**：生图、三维、代码三种来路要像一家，靠同一道调色、同一方向的光、同一面对照墙。
- **性能**：粒子上限 60（手机 30）、背景 WebP、家具两档尺寸懒加载、canvas 只在进场时开。
- **可读性**：暗底上的字加描边，正文区平纸，写进圣经。
- **呆板与乱**：同类物件站成一排就是贴图不是场（错落规则在圣经第八之二节）；功能页背景里留着首页的碑就乱（空场背景）；主角太小就不像主角（尺寸下限在圣经第八之三节）。
