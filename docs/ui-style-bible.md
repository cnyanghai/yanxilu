## 零、第四稿方向：整体就是图四的风格（2026-11-06 深夜，用户定）

用户看了 P011 后说：发来的图（Sleepy Hollow 铁门）从颜色、构图到标牌和字体都比生成的好，**要的整体就是这个风格**。量过两张图后原因是具体的，下面每条都改成规则，和第三稿冲突的以这里为准；全文重写等模型对比（P012）过门后做。

| 量什么 | 参考图四 | 我们 P011 第 1 张 | 结论 |
|---|---|---|---|
| 色相 | 青 55% 加蓝 27%，红橙 15%，只有冷暖两家 | 蓝紫 61%、青绿 19%、再加琥珀，三家打架 | 两色对撞：冷青占八成，火橙占两成，没有第三种颜色 |
| 明度 | 暗 45、次暗 40、中 12、亮 3、最亮 1 | 暗 67、次暗 26、中 6、亮 1、最亮 0 | 我们没有中间调和亮部，整张糊在暗里；光源要在主角后面 |
| 饱和 | 0.46 | 0.38 | 暖光处要饱和、冷处可灰 |

规则（第四稿）：
1. **色板**：冷青 #1E3A4A / #2E6B7A / #8FC4CC，火橙 #E8762B / #F4A742 / #FFD48A，铁黑 #0B0D12 / #1C2029，雾青白 #A9C6CC，锈褐 #5A3A22。紫夜与毒绿退役。色弱：青对橙是蓝橙轴，对红绿色弱最稳，比紫对绿好；意义仍不放在颜色上。
2. **光**：一张图一个主光，放在主角背后（天上的火、门后的光），主角是黑剪影、边缘被暖光勾出来；牌、灯、窗是暖光芯。碎光（烛、碑眼、月）至多一处。
3. **明度三层**：前景黑剪影（明度 ≤ 15%），中景雾青（40 到 60%），远景更浅更灰；暖光芯 80% 以上。出图后量五档，中间三档合计要 ≥ 15%。
4. **一屏一主角**：提示词里点名的东西不超过五样，主角占画面一半以上，对称或近对称，一条路把眼睛引进去。首页的主角是门，主字是牌。
5. **字是画出来的光，但一律由我们叠**（用户 2026-11-06 深夜定：所有字都留白，我们自己叠字）：生图提示词里牌、碑、路牌、封面一律写 blank，图里不准出现任何字；字由代码做成发光的锈铁字（牌后透光、外发光、锈纹字芯、暗边），字体隶书，字芯比光晕亮一档；路牌字同法缩小。模型自己画了字的图，用 edit 端点擦空再用（P013）。这样换字、换语言、换名字都不用重出图。
6. **竖幅优先**：手机是主战场，先出 2:3 竖图；桌面版用竖图加两侧黑树延展，不另出一套构图。
7. **带锚出图、四选一**：每件生图都带图四（或已定稿的我们自己的图）当风格锚走 edit 端点；每件至少出四张挑一，不再两张就用。
8. **模型**：用户定先只用 nano（nano-banana-pro，fal 端点 `fal-ai/nano-banana-pro/edit` 带锚图；1K 每张 0.15 美元约 1.1 元，2K 约 1.6 元）；gpt-image-2 偏插画、细节平均、整体偏暗，退为备用。
11. **手机阅读页以读为先**（用户 2026-11-06 深夜）：阅读页是单页骨白纸铺满屏，只有两条细石尺和极淡纸纹，不画场景；正文 18 像素可调、行高 1.75、对比 ≥ 9:1，夜读有墨黑纸；墓园只出现在架上与封面两屏。桌面宽屏才用对开。细则在分镜三之二节。
10. **书不用代码画**（用户 2026-11-06 深夜：现在缺的是书架中书的建模）：书脊是插画级的东西，和厚涂的柜子要一个世界。生产方式定为**生图零件表**：一张表十六根不同的空书脊（皮面、布面、黑铁箍、骨白犊皮、锈橙皮，厚薄高矮不一，有凸棱与压线，题签处留白），正视图、同一光（烛光从左上）、洋红底，`cut.py --split` 拆成单根；每本书按编号从零件表里稳定挑一根，题签用隶书叠在留白处；状态用代码叠在零件上：未读半透明青色幽灵、在读书口一线橙光、读完书口一线金。抽出来的书另出封面正视图零件表（展台用），同法。书脊零件按 2x 出（原图每根约 80×350 像素，架上 1x 高约 60 到 80 像素）。
9. **站名与字体**：软件改名**「邮差」**（用户 2026-11-06 深夜定）；标题与牌名字体用**隶书**（本机 SIMLI.TTF，上线前换可分发的隶书字体文件进 vendor/fonts），做成发光锈铁字。


## 一、一句话

紫夜的墓场。风暴般的紫云、黑的枯枝从画面顶上压下来、贴地的毒绿雾、灰蓝的碑、黑铁黑木的哥特尖拱，碑上的眼和幽灵发绿光，烛火发琥珀光，远处山上一座亮着窗的宅子。画法是**厚涂加墨线**：大笔触的硬边色块、石头和树木有墨色描边、剪影强、纸纹淡。**阴森但不血腥**：没有血、没有伤，骷髅是书童和书架的饰物，幽灵是书的魂，一切干净、可读。

## 三、线

- 墨黑描边：碑、树、木、铁、骨都描；云、雾、光、幽灵不描，用硬边色块和柔光。
- 外轮廓约物件边长的 2%，1x 下约 3 像素；转角与暗部加粗，受光面可断线。
- 云是大笔触的硬边色块（参考图一），不是渐变。

## 四、光

- **两盏光**：绿光是幽灵与地气（碑眼、雾、汇聚的书魂，从下面来），烛光是注意力（在读的书、选中的碑、递过来的本子，从近处来）。月光只做天空的明暗，不打到物件上。
- 剪影优先：树、碑、宅子先是黑影，再在受光面给一两档亮。
- 投影融进雾里，不画长影。

## 六、纸纹与正文可读性

- 全站一张纸纹叠加图，4% 到 6%。正文区（阅读器、翻开的书、本子纸面、卡面）一律骨白平纸、墨黑字，对比 ≥ 7:1，字号 ≥ 16 像素。

## 八之二、排布：错落

同类物件站成一排是最呆的（用户 2026-11-06 看灰盒时指出）。规则：
- **不等**：同类物件三种变体轮着用，高矮宽窄不同；间距不等，差 20% 到 40%。
- **前后两排**：后排缩到 0.75 到 0.8、底边抬高、脚下雾更浓、整体压暗一档；前排清楚。一屏前排至多五件、后排至多四件。
- **歪**：每件歪 3 到 8 度，左右交替，不整齐。
- **主角在前**：随手本的那只手、在读的那一架、最近动过的那座碑，站最前、最大、最亮（烛在它旁边）。
- **稳**：错落由物件的编号做种子算出来，同一件东西每次进来都站在同一个位置，不乱跳。

## 八之三、尺寸：主角要大，字要读得清

用户 2026-11-06 看第一次拼样：书架太小、碑太小看不清字。规则：
- **背景分两张**：首页用「墓园大门」（前景一道门框住画面、门内一条路，见下一条）；三个功能场一律用「空场」（同一片天、枯枝、宅子、路、雾，前景没有碑）。功能页里不准出现首页的门与路牌，画面里只有当前这个场的东西。
- **首页三层**（用户 2026-11-06 晚看图四：三碑首页的碑太大太多、层次不够）：前景是黑铁墓园大门——两根风化石柱、顶上一道铁花拱托一块铁牌刻站名「研习录」、烛光琥珀从牌后透出，门扇向内半开，枯藤缠柱，柱顶各一只小石像鬼（不用图四的魔鬼脸）；中景是门内一条裂开的石板路和路边一根木路牌，三块牌写书架 / 档案架 / 笔记本，就是三个入口；远景是雾里的枯林和山上亮窗的宅子（与空场同一座：进门就是三个场所在的墓园）。三层对比递减：门最黑最清楚，路与路牌中等，远景灰在雾里。前景不放大碑，碑只作远景的小点缀。「继续上次」是门柱上挂的灯笼。天仍是紫夜，不用图四的红橙天。
- **宽柜**（用户 2026-11-06：单拱柜太窄装不下书；看过三拱位示意后改定：只要一个拱位，做宽、做大）：一座黑哥特宽柜，一个尖拱横跨整个柜顶，比例 2:1，是书架场唯一的主角；宽 ≥ 视口的 90%、高 ≥ 视口的 80%。五到六层长格贯通整宽，一层格就是一个领域，领域名刻在格层左端的小木牌上；书脊宽 ≥ 16 像素（1x）才点得中、读得出，一层约装六十到八十本，一柜四百本上下。一个领域装不下就再占一层，柜身向下长、页面竖着滑，书和柜都不缩小。手机上宽柜按格层切开竖排，一屏一到两层，书脊照样 ≥ 16 像素。
- **档案碑**：前排碑高 ≥ 视口高的 45%，碑面刻名字号 ≥ 22 像素（1x），加墨黑描边；前排至多四座，后排至多三座、缩到 0.75；再多就翻页或横向滑，不缩小。
- **骨臂**：前排高 ≥ 视口高的 55%，本子封面上的题签 ≥ 18 像素。
- **手机**：一屏一座，宽占 70% 以上；碑上的字 ≥ 20 像素。
- **字永远在空板上**：碑面的刻字区是一块平的浅板，不压雕饰。

## 九、动效词汇

进场三段见 `ui-scene-motion.md`（钻出 / 长出 / 伸出，汇聚，落定；全长 3.5 秒、短版 0.8 秒、点一下跳过）。
常用词汇八个：幽灵汇聚、烛点亮、翻开（书 / 碑面 / 本子）、卡片圆弧摆开、盖印、落土、雾流、碑眼睁开。
时长 180 到 420 毫秒，缓出；雾流与碑眼眨是仅有的常驻动效；`prefers-reduced-motion` 时全部关掉只留状态变化。
