# 书柜（书架场景）生产计划 · 专业流程

2026-11-06 用户定：以后三维设计一律按专业流程做。本件是第一件，也是流程的样板。蓝本 `concepts/shelf-scene/B-warm-chestnut.webp`；借 A 的雕花与烛台。做在桌面 Blender（端口 9877）的 `yanxilu_props.blend` 里，脚本落 `tools/blender/web_props/`。

## 原则

- 读图不抄图：按物理做材质与光，不逐像素追蓝本。
- 每阶段一道门，门上必须有"我们 对 蓝本"的并排图，用户点头才进下一阶段。
- 一次只动一个量；EEVEE 实时预览截图，Cycles 只在过门时渲。
- 雕花与有机形不用基本体拼：用图生三维（从蓝本局部出）或 CC0 资产。
- 贴图 4K、按每米像素定密度；只放本机与 Windows 侧，不入库。

## 阶段 2 记录（高模）

2026-11-06 脚本 `tools/blender/web_props/bookcase_hipoly.py`，185 个物体、1.17 万面，场景 `yanxilu_hipoly.blend`。做法：

- 截面拉伸：柱身带七道半圆凹槽的截面拉到高度，槽上下留平段；
- 阵列：齿沿拱与檐口按弧长排，颈线珠一排；背板 16 块竖板带缝倒角；门板起线加黄铜钮；烛台三节；

- 雕花占位（粉色）：柱头嵌板玫瑰花、两侧涡卷，下一步图生三维替换。
第一轮拱带做在柱头前面（蓝本里柱头压在拱带上），第二轮拱带后退 0.08。
门交付：线框图 `tools/out/hipoly_wire.png`、正视 `hipoly_full.png`、三处近景对蓝本局部 `hipoly-vs-B.jpg`（不入库）。

## 阶段 3 记录（UV 与分层材质）

2026-11-06 脚本 `tools/blender/web_props/bookcase_materials.py`，在高模窗口里按物体名指派，不重建几何。贴图 Poly Haven 4K（mocha_oak_veneer、grey_plaster 各四张，Windows 侧 tex/，不入库）。
- 木（三档：柜身 / 线脚与立柱略亮 / 背板与嵌板底更深，加地板）：物体坐标盒投影 + 每个物体随机偏移与色相明度微变（每块板不同）→ 对比 → 色调 → 乘 AO；棱角磨损用 Bevel 法线与几何法线夹角做遮罩（棱上提亮加糙）；缝隙积灰用 AO 节点（暗处偏灰偏哑、清漆减弱）；粗糙 = 贴图 × 系数 + 磨损 + 积灰；法线 1.9；清漆 0.2 到 0.35。
- 黄铜：金属，两层噪声做指纹粗糙 0.16 到 0.34，棱角磨出新铜（更亮），微凹凸。
- 灰泥：4K 底材去饱和、压对比，叠大尺度云状斑驳，赭色调，法线 1.6。
- 蜡：次表面；暗缝底板近黑；火苗自发光。
三轮：第一轮整体过亮（每板明度偏移抬亮、灯太强）；第二轮木色压到胡桃、灯压低、黄铜加深、灰泥赭色；第三轮黄铜更深更亮、木纹对比 0.7、法线 1.9。
门交付：`tools/out/mat-vs-B-3.jpg`（木 / 黄铜 / 灰泥 / 柱头与蜡烛四块对蓝本局部）、`mat_full.png`（中性光整柜）。注意这一阶段是中性光，墙色与明暗气氛属阶段 4。

## 阶段 5 记录（分层渲染与合成）
