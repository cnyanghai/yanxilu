# 书柜（书架场景）生产计划 · 专业流程

2026-11-06 用户定：以后三维设计一律按专业流程做。本件是第一件，也是流程的样板。蓝本 `concepts/shelf-scene/B-warm-chestnut.webp`；借 A 的雕花与烛台。做在桌面 Blender（端口 9877）的 `yanxilu_props.blend` 里，脚本落 `tools/blender/web_props/`。

## 原则

- 读图不抄图：按物理做材质与光，不逐像素追蓝本。
- 每阶段一道门，门上必须有"我们 对 蓝本"的并排图，用户点头才进下一阶段。
- 一次只动一个量；EEVEE 实时预览截图，Cycles 只在过门时渲。
- 雕花与有机形不用基本体拼：用图生三维（从蓝本局部出）或 CC0 资产。
- 贴图 4K、按每米像素定密度；只放本机与 Windows 侧，不入库。

## 阶段与门

| 阶段 | 做什么 | 门（交付物） | 预算 |
|---|---|---|---|
| 0 参考与量尺 | 蓝本放大两倍；量柜宽高、层距、柱宽、拱矢高、线脚厚度等比例表；材质参考板（木、灰泥、黄铜各三张特写）；校机位，蓝本与粗模叠图 | 量尺表 + 叠图（线框压在蓝本上） | 半段 |
| 1 粗模 | 按量尺表改参数化骨架（现有脚本只留尺寸与布局） | 叠图偏差小于 2%，用户点头 | 半段 |
| 2 高模 | 型材库：檐口、冠线、搁板前沿、柱础、柱头顶板各一条截面曲线沿路径扫掠；齿、珠、凹槽阵列；雕花（玫瑰花、涡卷、拱心饰）图生三维或资产；全部倒角 | 线框图 + 近景无材质渲染，与蓝本局部并排 | 一段 |
| 3 UV 与材质 | 每块板独立 UV 与随机偏移色相；分层着色：底木、边缘磨损（倒角遮罩）、缝隙积灰（AO）、清漆；黄铜带指纹与磨损；灰泥两层；4K 贴图 | 四块材质球近景与蓝本局部并排 | 一段 |
| 4 看光 | HDRI 环境 + 主光 + 补光；EEVEE 并排蓝本，一次一个量；直方图与五区量值 | 直方图叠图 + 五区量值表 | 半段 |
| 5 分层渲染与合成 | Cycles 分层（漫反射、高光、AO、自发光、遮罩），合成调色、暗角、颗粒 | 混进蓝本与两张真书房照片，用户认不出 | 半段 |
| 6 出图进网页 | 分模块正交透明底（拱顶、格层、底座、立柱、墙面），层数 3 到 6 各一套；书由代码摆 | 网页上线对照图 | 半段 |

合计约四段半。每段结束更新本表与 STATUS。
