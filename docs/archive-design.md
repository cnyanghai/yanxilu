# 档案架、档案盒与打开后的页面 · 设计研究

2026-11-06 第一稿：只研究问题，不定方案。现状截图在本机 tools/out/ar-*.png、archive-current.jpg；参考墙 refwall-archive.jpg（维基共享，只在本机看）。

## 一、它现在是什么

三件东西，三层数据：

| 层 | 现在的样子 | 数据 |
|---|---|---|
| 档案架 | 一只黑漆重柜，六个格子按领域分（五个方向加「收件匣」），格里立着盒子；格下一条黄铜标牌写领域与件数；柜顶横匾「研究档案」 | 领域 = `domains` 加内置五个 |
| 档案盒 | 竖立的牛皮纸文件盒：盒顶露出色签（件的类型）、盒面是竖排题签（卷号加盒名）、底部件数、拉手孔；状态用小标（年更、在做红丝带、结卷朱印）；盒子宽度随件数变厚 | 课题 = 内置 `LIB.topics` 加自立 `aboxes`；字段 title / question / answer / origin / books / line / note / status / since |
| 打开后 | 整屏盖一张深色木桌：标题区（卷号、盒名、领域、立卷、状态、件数）→ 课题问题与"现在的答案"→ 一排牌（牌背：圆光夜读小景、题签、类型钱币、来源、宝石）→ 宝石图例 → 牌册（目录表，可折）→ 来龙去脉（从哪来 / 用到的书 / 用得上）→ 备考 → 操作 | 件 = `LIB.reports`（href 到专题页）加剪报 `clips`（正文在 Baba） |

另有「剪报夹」：领域格里一只牛皮纸档案袋，没拆的封着，点开拆封，牌飞出来；拖牌到盒上就装盒。

已经立得住的：一个问题一盒、盒里按件编号、盒随件数变厚、牌背与宝石表示读没读、拆封动效、桌面的"场"感。这些是产品逻辑，不动。

## 二、设计问题（按分量排）

### 1. 空格子比盒子多，架子像没进货
六个格子里四个只有虚线的"新档案盒"。真档案架的饱满来自密度：卡片目录柜是几十个一样的小抽屉，档案库是一排排同规格的盒子（参考 3、4、13 到 16）。空格子的虚线占位是"后台"的语言。

### 2. 架子和书墙不是一套家具
书墙现在是（或将是）胡桃木拱形书柜；档案架是黑漆重柜加黄铜牌，像从别的屋子搬来的。审视稿第一条"一个房间四种材质"在这里最明显。

### 3. 盒子的信息层级反了
盒面上最大的字是竖排盒名，但真正要一眼看到的是"这一盒有多少、读到哪、要不要年更"。现在件数在最底一行小字，状态是三种小标各自为政。卡片目录柜的抽屉只有一个黄铜标牌框加手写标签（参考 3），信息只有一条，反而清楚。

### 4. 打开后的页面是三种语言拼的
标题区和课题问题是"文档"，一排牌是"游戏"，牌册和来龙去脉是"表格"。三段之间没有过渡，桌面的木纹只是背景，牌没有真正"摆在桌上"（没有投影、没有散落感、没有翻过的牌和没翻的牌的区别）。手机上这一页要滚五屏。

### 5. 牌的身份不够
牌背全是同一幅夜读小景，只有题签和颜色不同；类型（档案 / 数据 / 计划 / 纪要 / 剪报）只靠一个钱币上的单字。真卡牌一副牌里每张的牌面都不同，牌背才一样；我们正好反过来，玩家看到的永远是牌背。

### 6. 件打开后跳出了书房
专题页（档案、数据、计划）是独立 HTML 在新标签页打开，剪报在阅读器里打开；一个在房间里、一个跳出去。

### 7. 收件匣与剪报夹两个"待归位"
格里的"收件匣"和领域格里的"剪报夹"都是"还没装盒的东西"，分在两处，规则要读四条说明才明白。

### 8. 手机
手机上档案架是六个格子竖排、每格一屏高，大部分是空白；桌面页五屏长。

### 9. 色弱
件的类型色签（蓝、绿、红、黄、紫）里红绿并列；宝石"青读了 / 金批注 / 朱结卷"靠颜色。类型和状态都要有形状或文字兜底。

## 三、参考里能借什么

| 参考 | 借什么 |
|---|---|
| 卡片目录柜（参考 1 到 4） | 密度与统一：同规格小格阵列，每格一枚黄铜标牌框加一张手写卡，一个拉手。和书柜同一种木头就是同一套家具 |
| 鸽笼格 / 国家档案馆取件格（5 到 7） | "待取"的表达：空格是正常状态，有东西的格子露出纸边。收件匣可以就是几个鸽笼格 |
| 文书匣 / 便携书桌（8 到 10） | 盒子打开是一个"桌面"：盖子翻开、里面分格、文具与纸各有位置。打开一盒的页面可以就是这只匣子翻开 |
| 档案盒与霍林格盒（13 到 18） | 盒子的真实形制：灰板、金属包边、前脸一张标签、绳扣。我们的盒可以更像这个，少一点"文件盒"味 |
| 字盘（22、23） | 一盒里很多件时的排法：浅格阵列，每格一件 |
| 瓷器柜（26、27） | 展示型的柜：有背板、有层、东西朝前摆。和"牌摆在桌上"的另一种想法：牌立在柜里 |
| Are.na 的 channel 与 block | 一件可以同时属于多个盒（block 连到多个 channel）；我们现在一件只在一盒。要不要允许"一件两盒"是产品问题 |
| Zotero 用户的抱怨 | 元数据不说明"为什么归这里"。我们的"课题问题 + 现在的答案"正是解这个的，是长处，要放到最显眼的位置 |

## 四、方向（请用户选，下一步出样稿）

A. **同一套木器**：档案架改成和拱形书柜同一种胡桃木、同一盏灯的卡片目录柜式矮柜（按专业流程在 Blender 里建，和书柜共用材质与光）；格子变成小抽屉阵列，一盒一抽屉，抽屉前脸是黄铜标牌框加一张卡（卷号、盒名、件数、状态一行写完）；空抽屉也是抽屉，不再有虚线占位。收件匣是柜顶上的几个鸽笼格。
B. **盒子即匣子**：打开一盒不再是整屏深色木桌，而是这只文书匣在桌上翻开：盖子内侧写课题问题与答案（像匣盖内贴的字条），匣内分格摆牌（每格一件，牌面朝上），匣外一张"来龙去脉"的索引卡。牌册与操作收进匣子边上的小抽屉。
C. **牌面翻过来**：牌默认牌面朝上（标题、一句话、类型图标、来源、读到哪），牌背只在"没拆封"时出现。类型用五种边框或角标形状区分，不靠颜色。
D. **件不出房间**：专题页在房间里的阅读器打开（iframe 或同页加载），和剪报一样有划线与批注。
E. **手机**：档案架改成一列抽屉（每行一盒），点开一盒是匣子的单栏版。

我的建议：先定 A 和 C（看得见的两件），B 随 A 一起出样稿，D 和 E 是实现问题由我定。顺序：出 A、B 的概念图（gpt-image-2，先报提示词与价钱）→ 用户选 → Blender 按专业流程建 → 出图进网页。

## 五、先回到意义：卡放哪儿（2026-11-06 第二稿）

用户的话：先想档案盒的意义，不一定非做成盒子；先不用 Blender，用样稿的方式研究。摘的文章和网页已经是"一篇一张卡"（剪报是卡，一篇研究也是卡），问题是**这些卡用什么形式存放**。

### 1. 现在的盒子到底在替我们做什么

把"盒"拆开看，它同时干着四件事，这四件事其实可以分开：

| 盒在做的事 | 现在的实现 | 换别的形式时要保住的是什么 |
|---|---|---|
| 存放：卡有个家 | 一张卡只在一盒；没装盒的在收件匣 / 剪报夹 | 任何一张卡都找得到；没归位的卡有去处 |
| 归类：卡为谁而存 | 盒 = 一个课题（问题） | 卡是为回答某个问题存的，不是为了收藏 |
| 结论：答案长在哪 | 盒面的"课题问题 + 现在的答案" | 答案要和证据（卡）挨着，能越写越长 |
| 状态：读到哪、还活不活 | 宝石（未 / 读 / 批 / 引）、年更、在做、结卷 | 一眼看出哪些没读；一个课题能"结案" |

卡本身带的信息（代码 `cardHTML` / `clips`）：题签（标题）、类型（档案 / 数据 / 计划 / 纪要 / 剪报）、来源（知乎 / 公众号 / 网页 / 自己写的）、读完约几分钟、为什么存（note）、领域（track）、学到哪一步（gem）。这些是卡面上的，不随存放形式变。

真正该由存放形式回答的五个问题：
1. **一张卡能不能同时在两个地方？** 现在不能。研究时常见：一篇文章同时是两个问题的证据。
2. **卡和卡之间的关系要不要看得见？** 盒里是一排，没有关系；研究恰恰是在卡之间连线。
3. **结论写在哪？** 要离证据近，还要有地方越写越长。
4. **没归位的卡放哪、多久清一次？** 收件匣和剪报夹是两处。
5. **多少张卡之后这个形式会垮？** 一盒 30 张以上，一排牌就得横滚；板上 50 张以上就乱。

### 2. 外面怎么放卡

| 做法 | 形式 | 答第几题 | 结论 |
|---|---|---|---|
| mymind | 没有文件夹、没有标签，一个大卡流，只靠搜索和自动标 | 1（卡不属于任何地方）、4（没有"归位"这回事） | 零整理成本，但也没有"课题"这个意义；我们要的是研究，不是收藏。排除整体，借"不归位也能活"的态度 |
| Raindrop | 收藏夹（树状）加标签 | 4 | 就是文件夹，和我们的盒一样；不借 |
| Are.na | block 可连进多个 channel | 1 | "引卡"思路：一张卡可以在多处出现，原件只有一份。采纳思路 |
| Milanote / Kosmik / Muse | 空间板：卡随手摆，位置和远近就是意义，板里可嵌板 | 2 | 研究感最强，但要用户自己摆，手机难。借"一块板"做课题的工作面 |
| Luhmann 卡片盒 | 两只盒：一只放文献卡，一只放自己的想法卡；不按主题分格，固定编号加关键词索引 | 1、5 | "文献卡"与"想法卡"分开存，正好对应我们的剪报和研究；无限扩展。借两盒分工 |
| 实物：卡片目录柜 / 剪贴簿 / 卷宗 / 线索板 / 集换册 / 托盘 | 见下 | | 各取一种画成设想 |

### 3. 六种设想（样稿 docs/archive-card-forms.png）

甲 **卷宗**：一个课题一本牛皮纸卷宗，封面一张卷宗签（卷号、问题一句、件数、状态章）。翻开左页是"卷首"：课题问题与现在的答案，像结案报告越写越长；右页是卡一张压一张订在一起，可抽出来看。结卷就是系绳盖章。
　答 3、4 好（答案就在卷首；没归位的卡是"待立卷"一摞），答 1、2 差。离现在最近，改动最小。

乙 **研究册（剪贴簿）**：一个课题一册，卡是贴在页上的剪报，卡旁边的空白写批注和答案，读与写在同一页。和笔记本架同一族：笔记本里多一类"研究册"，档案架可以并进笔记本架。
　答 3 最好，答 1 靠"复印"（同一张卡贴进两册，原件只有一份），答 2 靠同页相邻。手机就是翻页。多了翻页不垮（答 5 好）。

丙 **线索板**：一个课题一块软木板，卡用图钉钉上，自由摆、拉线、分区贴便签；板中央一张大便签是现在的答案。
　答 2 最好，研究感最强；答 1 靠复印；答 5 差（50 张以上乱），手机只能看缩略不能摆。适合做"工作面"而不是"存放处"。

丁 **卡片柜（一只长抽屉）**：所有卡立在一只长抽屉里，只露卡顶（题签、类型角标、宝石），用分隔签分段：最前面一段是"没归位"，其后每个课题一段；分隔签那张导卡上写问题与答案。一张卡要属于两个课题，就插一张"引卡"（只有题签，指向原件）。
　答 1、4、5 最好（无限扩展、密度、统一），答 2 差，答 3 一般（导卡空间小）。这是 Luhmann 与卡片目录柜的做法，和书柜同一种木头就是同一套家具。

戊 **牌册（集换册）**：一个课题一页九宫格透明袋，牌面朝上，多了翻页。
　展示性最好、牌的身份最清楚，但答案没地方写，像收藏不像研究。答 3 差。只借"牌面朝上"的排法（即方向 C）。

己 **桌面堆（托盘）**：不分课题，卡按状态堆成三摞：待读 / 读过 / 批过，课题只是卡上的一个标签，靠筛选成堆。
　零整理成本（mymind 的路），答 4 最好；但"课题"消失了，答 2、3 没有。排除作为主形式，借它做"没归位的卡"的样子。

### 4. 我的建议：存放和使用分开

现在的盒子把"卡存在哪"和"我在研究什么"绑成一件事，所以一张卡只能在一盒、空盒子难看、答案没地方长。分开以后：

- **存放用丁**：一只卡片柜（一只长抽屉或几只），所有卡都在这里，没归位的在最前一段。它回答"找得到、放得下、同一套家具"。剪报夹、收件匣合并成抽屉最前面那一段，拆封动效保留（封着的卡顶露一截封条）。
- **使用用乙**：课题是一本研究册，从柜里抽卡"贴"进册页，旁边写答案；一张卡可以贴进几册，原件在柜里只有一份。研究册放在笔记本架上，和随手本同架。结卷就是合上册子贴封条。
- **丙作为研究册的一种页面**：一册里可以有一页"板"，把这一册的卡摆开拉线；不是独立家具。
- 架子本身：档案架就不再是一件家具，变成"卡片柜"（存）加"笔记本架"（用）。房间里少一样东西，和审视稿"一个房间四种材质"的方向一致。

这样方向 A（同一套木器的目录柜）仍成立，只是柜里存的是卡不是盒；方向 B（盒即匣子）改成"册即工作面"；C 牌面朝上保留；D、E 不变。

### 5. 请用户定的事

1. 存放和使用分开（丁 + 乙）这个底子对不对；还是宁可留"一个课题一盒"的直觉，走甲（卷宗）。
2. 一张卡允许在多个课题里出现吗（引卡 / 复印）。
3. 研究册放笔记本架上，档案架这个入口要不要取消（切换条从"书墙 / 档案架 / 笔记本架"变成"书墙 / 卡片柜 / 笔记本架"）。
4. 要不要线索板那一页（丙）。
