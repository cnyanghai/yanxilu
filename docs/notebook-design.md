# 笔记本设计稿

2026-11-04 第一稿。查前作业在 REFERENCES.md「笔记本设计调研」；三维版（yanxilu-world）2026-10-30 已定"笔记本是书架上的实体、多本、日记并入"，本稿与之对齐，两边共用同一份数据。样稿图 `docs/notebook-mock.png`（源 `docs/notebook-mock.html`）。

按惯例：看得见的事由用户定（第 9 节列出来），技术由 Claude 定并记在这里。

## 1. 一句话

书架上多一件家具「笔记本架」，架上立着几本布面笔记本；随手本打开就是今天这一页；在任何页面按一下「记一笔」，写完回车就进了今天这一页；页里写到的书和档案盒自动成链，书的展台和盒的桌面上能看到"笔记本里提到过它"。

## 2. 目标与不做什么

目标：随时能记，记了能找回来，记下的东西能和书房里的书、盒、线网连起来，而不是另一座孤岛。

不做：块编辑器、数据库视图、白板、多人协作、手写、AI 总结（以后再议）。不做文件夹树。

## 3. 落位

- 书架的切换条变成三件家具：书墙 · 档案架 · 笔记本架。地址 `#notes`。
- 现在的摘抄册并进来，成为架上的一本自动生成的本子（见 5.2），地址 `#marks` 保留并转到那一本。
- 顶栏搜索放大镜旁边加「记一笔」（铅笔图标）。手机上是右下角的浮钮。
- 一本笔记本 `#nb-<id>`，一页 `#np-<id>`。全站搜索加「笔记」一类。

## 4. 看得见的样子

### 4.1 笔记本架

一只矮的斜面展示架（和三维版 ASSET-SPEC 里的笔记本架同一件），本子立着一排，封面朝前微仰。每本：布面封皮，六种低饱和色之一（墨青、本色、赭、炭、灰绿、暖灰，和三维版同一组），下沿一枚黄铜题签刻本名，书口露出纸页，页数多的本子更厚。架子右端留一本虚线轮廓「＋ 新本子」。指到一本略抬起；点一本翻开。

### 4.2 本子有三种

| 种类 | 怎么来 | 页按什么排 | 第一版 |
|---|---|---|---|
| 随手本 | 自带一本，删不掉 | 按日期，一天一页 | 是 |
| 主题本 | 自己立：名字、封面色、可选挂在哪个领域 | 自己建页，按建立时间 | 第二版 |
| 摘抄册 | 自动生成，不存 | 划线与批注按书分 | 并入时做 |

### 4.3 翻开一本：两页对开

桌面宽度下是一张对开。左页是目录：随手本是当月日历，写过的日子有墨点，下面列最近的页；主题本是页目录。右页是正文。纸面是现在阅读器那种微黄纸，中缝有一道装订阴影。手机上只有一页，目录收成顶部的下拉。

### 4.4 一页

- 页眉：随手本写日期和星期（十一月四日 · 周三），主题本写标题（可改）。
- 正文：文本。写的时候是一个干净的文本框；离开或失焦后渲染成排好的纸面（标题、列表、粗体、引用、公式、链接）；点纸面任意处回到编辑。
- 随手本的一页里，「记一笔」每次追加一段，段首有时间（14:32）。
- 页脚：字数、写于、改于；按钮「装进档案盒」「链到这本书」。

### 4.5 记一笔

一张小纸条从顶栏落下来（手机从底部升起），只有一个输入框。回车存到随手本今天这一页，Shift 加回车换行，Esc 收起，存完有一声轻响与 toast「记到今天的随手本了」。如果当前正开着一本书的展台或一个盒的桌面，纸条顶上多一行"记到《书名》"的开关，开了这一笔同时链到它。

快捷键：桌面在非输入状态按 `N`；全站搜索 Ctrl + K 里输入以 `+` 开头的文字也等于记一笔。

### 4.6 链接与回链

正文里输入 `《` 弹出书名联想，输入 `「` 弹出档案盒联想，也可以手写 `[[书名]]`。渲染成一小块书脊色加书名的链块，点它去展台或桌面。反过来，书的展台「更多」里和盒的桌面上有一行「笔记本里提到 3 次」，点开按日期列出那几段。

### 4.7 装盒

页脚「装进档案盒」把这一页登记为那个盒里的一件（件类型「纪要」）。页仍在本子里，盒里的牌背写"来自随手本 · 十一月四日"。这是"零散的先进收件匣，攒到两件再装盒"那条归档规矩的落地。

### 4.8 回顾

首页复习入口旁边，每天给一段旧页（一年前的今天、一个月前的今天、随机），一句话加"打开那一页"。可以在布置里关掉。第二版。

## 5. 数据（和三维版共用）

### 5.1 集合

- `nbooks`：一本笔记本。`{ name, color, domain?, kind: "daily" | "topic", order, t }`。文档 id `nb-` 加六位随机。随手本固定 id `nb-daily`，不存也视为存在。
- `pages`：一页。`{ nb, date: "2026-11-04", title?, text, tags: [], links: [{ k: "book" | "box", id }], box?, t, m }`。文档 id `np-` 加日期加四位随机；随手本一天只有一页，id 固定为 `np-d-2026-11-04`。
- 正文直接存在 `pages` 里，不像剪报分表：笔记是自己写的短文，一页几千字以内；超过 50 KB 提示另起一页。
- 公开版存 localStorage（`yanxilu-local` 现有机制），服务器版走 `/api/yxl/`。服务器端没有集合白名单，不用改 Baba。
- 摘抄册不存，运行时由 `marks` 生成。

### 5.2 读写

- 边写边存：停笔 800 毫秒写一次 `put("pages", id, …)`，沿用现有的按文档串行写链。
- 链接在存的时候解析：扫正文里的 `《…》`、`「…」`、`[[…]]`，匹配到书或盒就记进 `links`，回链按 `links` 反查，不全文搜。
- 全站搜索索引加 `pages` 的标题、日期与正文前 200 字。
- 导出：一本导出成一个 Markdown 文件（一页一个二级标题），用户自己的字随时能带走。

### 5.3 与三维版

三维版的笔记本架读同一个 `nbooks`，架上本数、封面色、厚度（按页数）由数据生成；页的阅读与编辑面板复用本仓库的阅读器思路。两边约定：不改字段含义，加字段可以。

## 6. 编辑器

- 一个 `textarea`，不用富文本库。渲染端用现成的 Markdown 子集（标题、列表、粗体、引用、分隔线、链接、行内代码）加 KaTeX（已在 vendor）。
- 不做所见即所得：手机上文本框最稳，渲染后的纸面只在不编辑时显示。
- 输入联想只做两种触发（`《` 与 `「`），列表取前 8 个匹配。

## 7. 手机

- 右下角浮钮「记一笔」，纸条从底部升起，键盘弹出时跟着上移。
- 翻开的本子单页显示，顶部一行日期可左右翻。
- 笔记本架改成两排。

## 8. 分版与验收

第一版：笔记本架（只有随手本一本和「＋ 新本子」占位）、记一笔、今天这一页、按日翻页、边写边存、全站搜索。

验收：

1. 任何页面按 N 或点铅笔，三秒内写完一句回车，刷新后在随手本今天这一页能看到。
2. 手机上同样的事一只手能完成。
3. 断网时记的一笔，恢复后自动写上去（现有串行写链已保证）。
4. 全站搜索能搜到昨天记的字，回车直达那一页。
5. 书架切换条三件家具并排，笔记本架在 1400 宽下和书墙、档案架一样整。

第二版：多本（主题本）、链接与回链、装盒、摘抄册并入、回顾、导出。
